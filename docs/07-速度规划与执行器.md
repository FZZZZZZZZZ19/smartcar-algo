# 07 · 速度规划与执行器

> 代码：`include/sc/speed_planner.h`、`src/speed_planner.c`、`include/sc/servo.h`、`src/servo.c`、`include/sc/motor.h`、`src/motor.c`
> 测试：`test_speed_and_actuators`

路径跟踪决定“往哪打”，速度规划决定“跑多快”。两者是解耦的，但只有在**转弯前把速度降下来**，横向控制器才有余量。

执行器模型则决定“指令能不能被执行”：舵机有最大角速度，电机有死区和掉压。忽略这些，仿真里完美的控制器上实车就会振。

---

## 1. 曲率限速

过弯时，侧向加速度不能超过轮胎/地面的附着极限：

```
a_lat = v² * κ
```

所以：

```
v_max = sqrt(a_lat_max / |κ|)
```

直线 `κ ≈ 0` 时取全局最高速度。

代码：

```c
float v = sc_speed_limit_from_curvature(kappa, a_lat_max, v_max);
```

`a_lat_max` 取值：

- 普通橡胶轮胎、干净赛道：3~5 m/s²。
- 湿滑/灰尘：1.5~2.5 m/s²。
- 实车先保守，再逐步加。

这个公式只考虑稳态侧向加速度，没有考虑载荷转移、轮胎非线性。实际能过的速度通常比理论值低，留 10~20% 余量。

---

## 2. 全局速度剖面

只知道每点的曲率限速还不够：车在直道末端可能速度很高，进弯前来不及刹车。

### 2.1 三次扫描

**第一步：曲率限速**

```
v[i] = min(v_max, sqrt(a_lat / |κ[i]|))
```

**第二步：反向扫描（保证刹得住）**

从后往前：

```
v[i] = min(v[i], sqrt(v[i+1]² + 2 a_dec ds))
```

**第三步：正向扫描（保证加得起来）**

从前往后：

```
v[i] = min(v[i], sqrt(v[i-1]² + 2 a_acc ds))
```

代码：

```c
sc_speed_profile_build(kappa, n, ds, v_max,
                       a_lat, a_acc, a_dec,
                       /*closed=*/1, v_out, /*passes=*/4);
```

### 2.2 为什么闭环要多迭代

闭环路径的首尾是连着的。反向扫描到 `i=0` 时，还要用 `v[n-1]` 约束 `v[0]`；正向扫描同理。一次扫描无法让首尾同时满足，迭代 3~4 次就收敛了。

### 2.3 参数

- `a_lat`：侧向加速度上限，决定弯道速度。
- `a_acc`：纵向加速度上限，决定出弯加速。
- `a_dec`：减速度上限，决定刹车距离。

实车 `a_dec` 通常比 `a_acc` 大（刹车比加速容易），但受轮胎抱死限制。

## 3. 梯形速度规划

已知一段距离 `D`，从 `v0` 到 `v1`，最大速度 `v_max`，加减速度 `a_acc`、`a_dec`。

### 3.1 距离足够

```
s_acc = (v_max² - v0²) / (2 a_acc)
s_dec = (v_max² - v1²) / (2 a_dec)
s_cruise = D - s_acc - s_dec
```

如果 `s_cruise >= 0`，就是“加速 → 匀速 → 减速”三段。

### 3.2 距离不够

解方程：

```
(v² - v0²)/(2 a_acc) + (v² - v1²)/(2 a_dec) = D
```

得到实际峰值：

```
v² = (2D + v0²/a_acc + v1²/a_dec) / (1/a_acc + 1/a_dec)
```

代码：

```c
sc_trap_t trap;
sc_trap_plan(&trap, distance, v0, v1, v_max, a_acc, a_dec);

float v = sc_trap_speed_at_distance(&trap, s, v0, v1, a_acc, a_dec);
```

`trap.feasible == 0` 表示距离太短，连从 `v0` 减速到 `v1` 都不够。这时规划器会给出一个不可行的剖面，调用方应该提前减速或放弃该目标。

### 3.3 什么时候用

- 定点停车。
- 发车/停车。
- 一段已知长度的直道冲刺。

整条赛道一般用第 2 节的全局剖面，而不是逐段梯形。

---

## 4. 在线 S 型速度规划

梯形规划的速度曲线有加速度突变（jerk 无穷大），实车上会让轮胎突然受冲击，容易打滑。

S 型规划限制加加速度（jerk）：

```
a_des = clamp(k (v_target - v), -a_max, a_max)
a = move_towards(a, a_des, j_max * dt)
v += a * dt
```

代码：

```c
sc_scurve_t sc;
sc_scurve_init(&sc, a_max, j_max, v0);
float v = sc_scurve_step(&sc, v_target, dt);
```

特点：

- 不需要预先知道距离，适合在线调整目标速度。
- 起步、刹车都平滑。
- 不是“时间最优”，会比梯形慢一点。

完整的七段式 S 曲线（加加速、匀加速、减加速、匀速、加减速、匀减速、减减速）更复杂，代码里没有实现；在线版本在智能车上足够用。

## 5. 舵机

### 5.1 角度到 PWM

```
pwm = pwm_center + k1 * delta + k2 * delta²
```

- `pwm_center`：机械中值。
- `k1`：主斜率。
- `k2`：二次项，补偿连杆非线性。

代码：

```c
sc_servo_t servo;
sc_servo_init(&servo, 1500.0f, 500.0f, 0.0f, 1000.0f, 2000.0f, 5.0f);
float pwm = sc_servo_update(&servo, delta_cmd, dt);
```

参数含义：中值 1500 us，每弧度 500 us，范围 1000~2000 us，最大角速度 5 rad/s。

### 5.2 标定

1. 给中值 PWM，调整机械中值，让车轮正前方。
2. 给左极限、右极限，记录 PWM，确认不顶死（顶死会烧舵机）。
3. 在中间取几个点，拟合 `k1`、`k2`。
4. 检查左右对称性：给 `+delta` 和 `-delta`，车轮转角应该对称。

### 5.3 斜率限制

舵机不是瞬间到位的。指令阶跃会让它全速冲过去，电流大、机械冲击大。

`sc_servo_update` 内置了 `max_rate` 限制：

```
angle = move_towards(angle, cmd, max_rate * dt)
```

`max_rate` 取舵机规格的 60~80%。

### 5.4 死区与回差

舵机齿轮有回差，正反方向到同一角度时 PWM 可能略有不同。高精度场合要做回差补偿，普通竞速可以忽略。

## 6. 电机

### 6.1 死区补偿

给小占空比时电机不转（静摩擦）。补偿：

```
cmd > 0: duty = deadzone + cmd * (max_duty - deadzone)
cmd < 0: duty = -deadzone + cmd * (max_duty - deadzone)
```

代码：

```c
sc_motor_t motor;
sc_motor_init(&motor, 0.1f, 1.0f, 1000.0f, 8.0f);
float duty = sc_motor_update(&motor, cmd, dt);
```

### 6.2 掉压补偿

电池电压从 8.4 V 掉到 7.0 V，同样的占空比，电机转速会下降。补偿：

```
duty *= V_nominal / V_now
```

`sc_motor_set_battery` 更新当前电压。注意别补偿过头，`duty` 还是要限幅。

### 6.3 斜率限制

电机突加满占空比会：

- 电流冲击，可能触发保护。
- 轮胎打滑。
- 机械冲击。

`slew` 限制占空比变化率。起步时也可以用 S 型速度规划，从上层就平滑。

### 6.4 电流环

如果驱动器支持电流环，速度环的输出应该给**目标电流/转矩**，而不是直接给占空比。电流环带宽高，能保护电机和驱动器。

代码里没有实现电流环（需要电流采样），但结构上可以：

```
速度 PID → 目标电流 → 电流 PID → PWM
```

## 7. 串级速度环示例

```c
/* 1. 速度规划：根据曲率给目标速度 */
float v_target = sc_track_speed(&track, s);

/* 2. 速度 PID：目标速度 → 占空比 */
float duty = sc_pid_update(&speed_pid, v_target, v_measured, dt);

/* 3. 电机模型：死区、掉压、斜率 */
float out = sc_motor_update(&motor, duty, dt);

/* 4. 输出到 PWM */
pwm_set_duty(out);
```

转向：

```c
/* 1. 路径跟踪：位姿 → 期望转角 */
float delta_cmd = sc_lqr_track_update(&lqr, e_y, e_psi, kappa);

/* 2. 舵机模型：限幅、斜率、标定 */
float pwm = sc_servo_update(&servo, delta_cmd, dt);

pwm_set_servo(pwm);
```

## 8. 实车注意

### 8.1 刹车距离

`s = v²/(2 a_dec)`。3 m/s、`a_dec=2` 时刹车距离 2.25 m。如果弯道前只有 1 m，必然冲出。

规划时要把**感知延迟 + 执行延迟**算进去：车在延迟期间还在前进。

### 8.2 轮胎附着

`a_lat` 和 `a_dec` 共享同一个附着圆：

```
sqrt(a_lat² + a_long²) <= μ g
```

一边急刹一边急转，很容易突破附着。规划时留余量。

### 8.3 电池

- 电压低时动力下降，速度环会加大占空比，电流更大，电压掉得更快。
- 比赛前充满电，或者做电压补偿。
- 低电压保护：低于阈值时降速。

### 8.4 传感器延迟

摄像头 30~60 ms，电磁 5~10 ms，编码器 1~5 ms。延迟会吃掉相位裕度。

补偿：

- 用运动学模型预测延迟后的位姿。
- 降低控制带宽。
- 用 IMU 提供短时高频的姿态/角速度。

### 8.5 机械限位

舵机左右极限、电机最大占空比，都要在软件里限死。不要依赖机械限位，会烧舵机。

## 10. 练习

1. 把 `a_lat` 从 3.5 改成 2.0，跑仿真，看圈速和最大横向误差怎么变。
2. 把 `a_dec` 改小到 1.0，观察速度剖面在弯道前是否还刹得住。
3. 给电机加一个 30% 的死区，比较有补偿和无补偿的起步响应。
4. 把电池电压从 8.4 改成 6.5，看占空比补偿的效果。
5. 设计一个“定点停车”场景，用梯形规划从 3 m/s 停到 0，验证停车位置误差。
