# 06 · 路径跟踪控制

> 代码：`include/sc/pure_pursuit.h`、`include/sc/stanley.h`、`include/sc/lqr.h`、`src/path.c`
> 测试：`test_path_tracking`
> 仿真：`sim/sim_common.c`，对比结果见 `out/sim_compare.svg`

路径跟踪要解决的问题：**已知一条参考路径，车当前有偏差，怎么打方向把车拉回去**。

三种主流方法：

- 纯跟踪（Pure Pursuit）：几何法，看一个前视点。
- Stanley：几何法，看横向误差和航向误差。
- LQR：最优控制，基于误差模型。

---

## 1. 路径表示与误差定义

代码用折线路径 + 弧长参数化：

```c
sc_path_t path;
sc_path_build(&path, x, y, s, n, /*closed=*/1);
```

核心函数：

```c
sc_path_project(&path, pose.x, pose.y, pose.theta,
                hint, window, &s, &e_y, &e_psi, &idx);
```

输出：

- `s`：投影点的弧长。
- `e_y`：横向误差，**正 = 车在路径左侧**。
- `e_psi`：航向误差，`theta - 路径切向`。

投影的几何：

```
路径切向 t = (cos ψ, sin ψ)
车相对投影点 d = (x - x_p, y - y_p)
e_y = t × d = t.x d.y - t.y d.x
```

叉积为正，说明车在左侧。

`e_psi` 要归一化到 `[-π, π]`，否则在 ±π 附近会跳变。

## 2. 纯跟踪 Pure Pursuit

### 2.1 几何推导

在路径上取一个前视点 `P`，距离车 `ld`。车要沿着一段圆弧走到 `P`，圆弧与车头方向相切。

设 `α` 是“车头方向”到“车到 P 的连线”的夹角：

```
α = atan2(P.y - y, P.x - x) - theta
```

由几何关系，圆弧半径：

```
R = ld / (2 sin α)
```

前轮转角：

```
delta = atan(L / R) = atan(2 L sin α / ld)
```

代码：

```c
sc_pure_pursuit_t pp;
sc_pp_init(&pp, L, ld_base, ld_gain, max_steer);

float ld = sc_pp_lookahead(&pp, v);
float tx, ty;
sc_path_lookahead(&path, s, ld, &tx, &ty, NULL);
float delta = sc_pp_steer(&pp, &pose, tx, ty);
```

### 2.2 前视距离

`ld` 是唯一关键参数：

- `ld` 小：贴线紧，但容易振荡，对噪声敏感。
- `ld` 大：平滑，但会“切内线”，弯道误差大。

常用自适应：

```
ld = ld_base + ld_gain * |v|
```

速度越快，看得越远。代码：

```c
pp.ld_base = 0.55f;
pp.ld_gain = 0.30f;
pp.ld_min = 0.30f;
pp.ld_max = 1.60f;
```

### 2.3 特点

优点：

- 实现简单，参数少。
- 天然平滑，适合高速。
- 不需要精确的车辆模型（只用轴距）。

缺点：

- 弯道有系统性内切误差。仿真里 RMS 3 cm，最大 9 cm。
- 前视点选在路径上，路径本身不平滑时输出会抖。
- 低速时前视距离太小会振荡。

改进：

- 前视点做插值/平滑。
- 根据曲率动态调 `ld`（弯道看近一点）。
- 加曲率前馈。

## 3. Stanley

### 3.1 公式

```
delta = -e_psi - atan(k * e_y / (|v| + soft))
```

两项：

- `-e_psi`：把车头对准路径切向。
- `-atan(k e_y / v)`：把车拉回中心线。

符号：`e_y > 0`（车在左）要右打，`e_psi > 0`（车头偏左）也要右打，所以两项都取负。

代码：

```c
sc_stanley_t st;
sc_stanley_init(&st, 2.0f, 0.45f, 0.55f);
sc_stanley_set_wheelbase(&st, L);

float delta = sc_stanley_steer_ff(&st, v, e_y, e_psi, kappa);
```

### 3.2 低速软化

`v → 0` 时 `atan(k e_y / v) → ±π/2`，输出会爆。分母加 `soft`：

```
atan(k e_y / (|v| + soft))
```

`soft` 取 0.3~1.0 m/s。

### 3.3 曲率前馈

经典 Stanley 没有前馈，在弯道上会有稳态误差。加：

```
delta += atan(L * kappa_ref)
```

代码里 `sc_stanley_steer_ff` 做了这件事。仿真对比：

| 版本 | RMS e_y |
|---|---:|
| 无前馈 | 0.122 m |
| 有前馈 | 0.0004 m |

差距非常大。**实车上也建议加**，因为路径曲率是可以从规划/感知拿到的。

### 3.4 特点

优点：

- 低速贴线好。
- 物理意义清晰（航向 + 横向）。
- 参数少（`k`、`soft`）。

缺点：

- 对噪声敏感，`e_y` 抖动会直接进舵机。
- 高速时 `atan(k e_y/v)` 变小，横向修正变弱，需要调 `k` 或加前馈。
- 没有显式的速度相关阻尼。

## 4. LQR

### 4.1 误差模型

以后轴为参考，小角度线性化：

```
e_y_dot   = v * e_psi
e_psi_dot = v/L * delta - v * kappa_ref
```

写成状态空间：

```
x = [e_y, e_psi]^T
A = [0  v]
    [0  0]
B = [0]
    [v/L]
```

### 4.2 离散化与 Riccati

前向欧拉：

```
Ad = I + A dt = [1  v dt]
                [0   1  ]
Bd = B dt = [0]
            [v dt / L]
```

代价函数：

```
J = Σ (x' Q x + R delta²)
```

离散 Riccati 迭代：

```
P = Q
repeat:
    S = R + B' P B
    K = S^-1 B' P A
    P = A' P A - A' P B K + Q
until converge
```

代码：`sc_lqr_discrete`，支持 8×8 以内的矩阵。

### 4.3 控制律

```
delta = -K x + atan(L * kappa_ref)
      = -k_y e_y - k_psi e_psi + 前馈
```

代码：

```c
sc_lqr_track_t lqr;
sc_lqr_track_init(&lqr, L, v, dt, q_y, q_psi, r_delta, max_steer);
float delta = sc_lqr_track_update(&lqr, e_y, e_psi, kappa_ref);
```

### 4.4 权重怎么选

- `q_y` 大：更在意横向误差，打角更积极。
- `q_psi` 大：更在意航向，转弯更平顺。
- `r_delta` 大：更在意转角代价，输出更保守。

经验起点：`q_y=1, q_psi=1.5, r=0.15`，然后根据实车响应调。

### 4.5 增益调度

`K` 和速度有关。速度变化大时，必须重算：

```c
if (fabsf(v - lqr.v) > 0.4f) {
    sc_lqr_track_rebuild(&lqr, v);
}
```

仿真的 5 ms 周期里，`v` 最多变 0.4 m/s，重算频率不高。

也可以离线算一张 `v → K` 的表，运行时插值。

### 4.6 特点

优点：

- 理论上最优（在模型和代价函数意义下）。
- 可以显式权衡误差和打角。
- 容易扩展（加转向速率、侧偏角等状态）。

缺点：

- 依赖模型。模型不准时，性能下降。
- 需要解 Riccati（离线算好即可）。
- 权重没有直观物理意义，调参靠试。
- 对噪声和延迟敏感，实车要加滤波、状态估计。

## 5. 三种方法对比

| 维度 | 纯跟踪 | Stanley | LQR |
|---|---|---|---|
| 原理 | 几何 | 几何 | 最优控制 |
| 参数 | 前视距离 | k、软化速度 | Q/R |
| 弯道误差 | 有内切 | 加前馈后很小 | 加前馈后很小 |
| 低速 | 容易振荡 | 好 | 好 |
| 高速 | 好 | 一般 | 好（需调度） |
| 对噪声 | 较鲁棒 | 敏感 | 敏感 |
| 模型依赖 | 低 | 低 | 高 |
| 实现难度 | 低 | 低 | 中 |

仿真结果（理想模型、无噪声）：

| 控制器 | RMS e_y | max |e_y| |
|---|---:|---:|
| 纯跟踪 | 0.0300 m | 0.0906 m |
| Stanley + 前馈 | 0.0004 m | 0.0018 m |
| LQR + 前馈 | 0.0009 m | 0.0029 m |

**别把这个排名当真。** 理想仿真里模型完全匹配，基于模型的方法占便宜。实车有噪声、延迟、滑移、模型失配，纯跟踪往往更“皮实”，LQR 调不好反而更容易振。

## 6. 预瞄控制

另一种常见结构：先预测“再过 `t_preview` 秒车会到哪”，把预测点投影到路径上，得到预瞄横向误差，再做 PD：

```
delta = -k_y * e_y_preview - k_psi * e_psi + atan(L * kappa_ref)
```

预测模型可以很简单（保持当前航向直行）：

```
x_p = x + v cos(theta) * t_preview
y_p = y + v sin(theta) * t_preview
```

代码：

```c
sc_preview_t pv;
sc_preview_init(&pv, L, /*preview_time=*/0.4f, /*k_y=*/2.0f,
                /*k_psi=*/1.0f, max_steer);

sc_pose2_t pred;
sc_preview_predict(&pv, &pose, v, &pred);

float s_p, e_y_p, e_psi_p, kappa;
sc_path_project(&path, pred.x, pred.y, pred.theta,
                hint, 20, &s_p, &e_y_p, &e_psi_p, NULL);
kappa = sc_path_curvature_at(&path, s_p, 0.25f);

float delta = sc_preview_steer(&pv, e_y_p, e_psi_p, kappa);
```

和纯跟踪的区别：

- 纯跟踪是几何圆弧，输出由前视点唯一决定。
- 预瞄控制是线性 PD，`k_y`、`k_psi` 可以独立调，物理意义更直观。
- 预瞄点是根据速度预测出来的，天然随速度自适应。

很多高速队伍用这种结构，因为它比纯跟踪好调，又比 LQR 依赖的模型少。

## 6.1 其他方法为什么少见

- **MPC**：理论上能处理约束（转角、加速度），但需要在线解 QP，主控算力通常不够；而且模型失配时优势不明显。少数队伍用显式 MPC 或短时域近似。
- **滑模控制**：鲁棒性好，但抖振（chattering）对舵机不友好，需要边界层/滤波，调参比 PID 难。
- **迭代学习**：重复跑同一条赛道时有效，但比赛只跑几圈，且元素可能变化，收益有限。
- **纯强化学习**：训练成本高、可解释性差、实车安全难保证，目前多停留在仿真/展示。

先把 PID、纯跟踪、Stanley、LQR 吃透，再考虑这些。

## 7. 实车注意事项

### 7.1 参考点一致

控制器用的 `e_y`、`e_psi` 必须和车辆模型/定位的参考点一致。如果定位用后轴，控制器却按前轴算，会有恒定偏移。

### 7.2 延迟补偿

摄像头有曝光+传输延迟（几十 ms），舵机有响应延迟。高速时，用当前位姿算出来的转角已经晚了。

补偿方法：

- 用运动学模型预测 `delay` 之后的位姿，再算转角。
- 或者用“预瞄”提前看。

### 7.3 转角速率限制

控制器输出的是“期望转角”，舵机有最大角速度。加斜率限制：

```c
delta = sc_slew_limit(delta_prev, delta_cmd, max_rate, dt);
```

仿真里用了 7 rad/s。

### 7.4 路径平滑

折线路径的曲率在顶点处是脉冲，会让控制器输出抖。用 Catmull-Rom 或样条平滑：

```c
sc_catmull_rom(ctrl_x, ctrl_y, n, 1, 64, out_x, out_y);
```

### 7.5 噪声

`e_y` 来自图像/电磁，噪声不小。进控制器前做低通或卡尔曼。但注意相位滞后。
