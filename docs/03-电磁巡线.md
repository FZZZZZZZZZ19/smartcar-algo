# 03 · 电磁巡线

> 代码：`include/sc/emag.h`、`src/emag.c`
> 测试：`test_emag`

电磁组用铺在赛道中心的漆包线通交流电，车上的电感线圈感应出电压。电压大小随“线圈到导线的距离”变化，由此反推车相对赛道中心的偏移。

和摄像头相比，电磁**不受光照影响、帧率高、成本低**，但信息量少：只有几个一维电压值，元素识别更依赖布局和状态机。

---

## 1. 物理直觉

长直导线通交流电 `I(t) = I0 sin(ωt)`，空间磁场：

```
B(d) = μ0 I / (2π d)
```

线圈感应电压正比于磁通变化率：

```
V ∝ ω I0 / d
```

也就是说，**离导线越近，电压越大**，大致按 `1/d` 衰减。

实际线圈有尺寸、有方向，近场更接近：

```
V(d) ≈ V0 * h² / (d² + h²)
```

`h` 是线圈离导线的高度，`d` 是横向距离。代码里的仿真函数就是这个模型：

```c
float sc_emag_sim_field(float sensor_y, float wire_y, float h);
```

它用来生成测试数据，不参与实车计算。

---

## 2. 传感器布局

### 2.1 水平电感

横跨赛道排布，用来测**横向偏移**。常见：

- 双电感：左、右各一个，最简单，只能测偏移方向。
- 三电感：左、中、右，可以判断导线在中间还是两侧。
- 五电感：左二、中、右二，覆盖更宽，元素判断更从容。

代码约定：`pos[]` 是传感器相对车体中心的横向坐标，**左正右负**，索引从左到右递减。

```
五电感示例：

   pos:  +0.16  +0.08   0.00  -0.08  -0.16
   idx:     0      1      2      3      4
         左远   左近    中    右近   右远
```

### 2.2 竖直电感

装在车头前方，线圈轴线竖直或斜置，用来判断**导线在前方还是后方**，以及辅助识别环岛、十字、坡道。

```
方向量 = (V_up - V_down) / (V_up + V_down)
```

正值表示导线偏前，负值偏后。

## 3. 归一化

原始 ADC 值受这些因素影响：

- 电源电压（电池从 8.4 V 掉到 7.0 V，读数整体变小）
- 温度（线圈电阻、电容参数漂移）
- 赛道电流（不同赛道、不同发车台可能不一样）
- 安装高度、线圈个体差异

所以不能直接用原始值。做法是逐通道归一化：

```
norm_i = (raw_i - min_i) / (max_i - min_i)
```

### 3.1 动态最大值跟踪

比赛时没法提前知道 `max`。常用“慢衰减 + 快上升”：

```
if raw > vmax:
    vmax = raw
else:
    vmax = decay * vmax + (1-decay) * raw
```

`vmax` 记录“曾经到过的峰值”，然后慢慢向当前值回落。这样车经过导线正上方时 `vmax` 被刷新，离开后不会立刻掉下来，归一化保持稳定。

代码：

```c
sc_emag_t emag;
sc_emag_init(&emag, 5, pos, 100.0f);   // 初始最大值
sc_emag_update(&emag, raw);            // 每帧更新 norm[]
```

`decay` 取 0.99~0.999。太小会让归一化跟着车的位置波动，太大则适应不了赛道变化。

### 3.2 手动标定

如果比赛前能扫描赛道，直接记录每个传感器的 `min`/`max`，用 `sc_emag_set_range` 写死，比动态跟踪稳。

## 4. 差比和

最经典、最常用的偏移解算：

```
ratio = (V_left - V_right) / (V_left + V_right)
```

范围 `[-1, 1]`，正表示导线在左。

### 4.1 为什么好

假设两个电感对称放在 `±d`，导线偏移 `Δ`，电压近似 `V = k / 距离`：

```
V_left  = k / (d + Δ)
V_right = k / (d - Δ)

(V_left - V_right) / (V_left + V_right) = Δ / d
```

**绝对场强 `k` 被约掉了**，只剩几何关系。所以电源电压、赛道电流变化都不影响结果。这是差比和最核心的优点。

### 4.2 局限

- 导线在正中间时，分母很小，噪声被放大。
- 偏移很大时，一侧电感几乎没信号，比值饱和。
- 只用了两个电感，信息量有限。

改进：

- 分母加一个小的常数，避免除零。
- 用 `tanh` 压缩饱和区（代码里 `sc_emag_offset_5` 就这么做）。
- 用更多电感做拟合。

代码：

```c
float ratio = sc_emag_diff_ratio(v_left, v_right);
```

## 5. 二次函数拟合

三个电感（或更多）时，可以把“电压 vs 位置”拟合成抛物线，顶点就是导线位置。

给定三个点 `(x0,y0), (x1,y1), (x2,y2)`，拟合：

```
y = a x² + b x + c
```

解出 `a`、`b` 后，顶点：

```
x* = -b / (2a)
```

代码：

```c
float pos[3] = {-0.05f, 0.0f, 0.05f};
float val[3] = { ... };   // 归一化后的电压
float offset = sc_emag_quadratic_offset(pos, val);
```

### 5.1 什么时候好用

- 导线在三个电感的覆盖范围内。
- 中间电感的读数最大，两侧递减，形状接近抛物线。
- 采样噪声小（先做中值/低通）。

如果 `a ≈ 0`（三点近似共线，比如导线在很远的地方），顶点公式会爆炸。代码里做了退化处理，回退到加权质心。

### 5.2 和差比和的关系

差比和是“两点”解算，二次拟合是“三点”解算。前者对绝对场强不敏感，后者能给出更细的分辨率，但更依赖标定和噪声水平。

实战里常见的组合：

```
粗定位：差比和，判断导线在左/中/右
精定位：二次拟合，给出厘米级偏移
```

## 6. 五电感解算

五电感最常用的做法是分组：

```
left  = norm[0] + norm[1]
right = norm[3] + norm[4]
ratio = (left - right) / (left + right)
offset = half_span * tanh(2 * ratio)
```

代码：`sc_emag_offset_5`。

中间电感 `norm[2]` 可以用来判断“导线是否在正中间”，也可以参与加权。

### 6.1 加权质心

另一种思路：把归一化电压当权重，求位置的加权平均：

```
offset = Σ(pos_i * w_i) / Σ w_i
w_i = norm_i ^ sharpness
```

`sharpness` 越大，越偏向最强的那个电感。代码：

```c
float offset = sc_emag_weighted_centroid(pos, norm, n, 1.5f);
```

优点是简单、天然支持任意数量电感；缺点是对远端电感的噪声敏感，且没有差比和那种“消除绝对场强”的性质。

## 7. 滤波

电磁信号干净，但仍有几个噪声源：

- 20 kHz 载波带来的纹波 → 采样同步 + 低通
- 电机 PWM 干扰 → 硬件滤波、远离动力线
- ADC 量化噪声 → 滑动平均

推荐链路：

```
ADC → 中值滤波（去脉冲）→ 一阶低通（去高频）→ 归一化 → 解算
```

代码里 `filter.c` 的 `sc_median_step`、`sc_lpf1_step` 可以直接用。

注意：**先滤波再归一化**。如果先归一化，动态最大值会把噪声峰值也记进去。

## 8. 元素识别

电磁的信息少，元素识别通常靠“布局 + 时序 + 状态机”。

### 8.1 十字

特征：

- 左右电感同时出现较强信号（导线分叉，两侧都有线）。
- 竖直电感可能同时感应到前后两条线。
- 持续时间短（车很快通过）。

处理：确认后保持直行，不要被横向偏差带偏。

### 8.2 环岛

特征：

- 进入环岛时，一侧电感信号突然增强/减弱，另一侧变化不大。
- 竖直电感的方向量会出现特征变化。
- 持续时间较长。

处理：状态机 + 里程计。很多队伍用“入环后走固定弧长”来出环，比纯电磁判断可靠。

### 8.3 坡道

特征：

- 车体俯仰角变化 → IMU 的 pitch 明显不为 0。
- 电感整体读数可能变化（离地高度变了）。

处理：IMU 辅助，坡道上降低速度、加大直立/平衡补偿。

### 8.4 三叉/分岔

特征：中线偏移量突然出现两个极值，或者左右电感同时增强。

处理：结合赛道记忆和里程，不要只靠单帧。

## 9. 标定清单

1. **静态标定**：车放在赛道中心，记录五个电感的原始值；再分别放在左偏 5、10、15 cm，记录数据。
2. **对称性**：左右对称位置读数应该接近。差很多说明线圈高度/角度不一致。
3. **高度**：线圈离导线越近，信号越强、分辨率越高，但动态范围变小。一般 5~15 cm。
4. **最大值**：手动把车推过导线正上方，记录每个通道的峰值。
5. **串扰**：单独给一个线圈信号，看其他通道有没有感应。有的话要加屏蔽或软件补偿。
6. **采样同步**：如果赛道电源是 20 kHz，ADC 采样率要足够高，或者做同步检波。
