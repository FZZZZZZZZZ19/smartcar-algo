# 08 · 仿真、调参与排错

> 代码：`sim/sim_common.c`、`sim/sim_main.c`、`sim/sim_compare.c`
> 输出：`out/*.csv`、`out/sim_compare.svg`

仿真的价值不是“证明算法对”，而是**让你在不上车的情况下，快速看清一个参数在做什么**。这一章讲仿真怎么跑、结果怎么读、参数怎么试。

---

## 1. 仿真结构

```
sim_track_build()
    ↓
控制点 → Catmull-Rom → 等弧长重采样 → 曲率 → 速度剖面
    ↓
sim_run(控制器的类型)
    ↓
每个 5 ms：
    投影到位姿 → 横向控制器 → 舵机限幅 → 运动学积分
    速度剖面 → 纵向 P 控制 → 加速度限制
    ↓
写 CSV + 统计指标
```

车辆模型是**运动学自行车**，没有质量、轮胎滑移、侧偏刚度。所以：

- 模型完全匹配时，LQR/Stanley 几乎无误差。
- 纯跟踪有几何内切误差。
- 不能用来预测实车极限圈速。

## 3. 指标怎么读

| 指标 | 含义 | 关注点 |
|---|---|---|
| RMS e_y | 横向误差均方根 | 整体贴线程度 |
| max |e_y| | 最大横向误差 | 最危险的时刻 |
| RMS e_psi | 航向误差 | 车头是否稳定 |
| mean_v | 平均速度 | 圈速潜力 |
| lap_time | 首圈时间 | 综合性能 |

注意：

- RMS 小不代表最大误差小。过弯瞬间的大误差可能被平均掉。
- 首圈包含起步加速，比较圈速要看第二圈。当前仿真只记录首圈，因为 24 s 跑两圈多一点。
- 速度剖面被 `0.95` 缩放，留了 5% 余量。

## 4. 参数实验

改 `sim/sim_common.c` 里的参数，重新 `make sim`，观察指标。建议一次只改一个。

### 4.1 纯跟踪前视距离

```c
sc_pp_init(&pp, 0.33f, 0.55f, 0.30f, 0.55f);
//                  ld_base  ld_gain
```

试：

- `ld_gain = 0.1`：前视距离小，贴线紧，可能振荡。
- `ld_gain = 0.8`：前视距离大，平滑，但切弯更多。

记录 RMS、max、圈速，找折中。

### 4.2 Stanley 增益

```c
sc_stanley_init(&st, 2.0f, 0.45f, 0.55f);
//                    k    soft
```

- `k` 大：横向修正强，但容易振。
- `k` 小：修正弱，弯道误差大。

### 4.3 LQR 权重

```c
sc_lqr_track_init(&lqr, 0.33f, 1.0f, SIM_DT, 1.0f, 1.5f, 0.15f, 0.55f);
//                                            q_y   q_psi  r
```

- `q_y` 大：更在意横向误差。
- `q_psi` 大：更在意航向。
- `r` 大：打角更保守。

### 4.4 速度

```c
#define SIM_V_MAX 3.2f
#define SIM_A_LAT 3.5f
```

提高 `V_MAX` 或 `A_LAT`，看横向误差是否还能保持。通常会有一个临界点，超过后误差迅速增大。

## 5. 调参方法论

### 5.1 先开环，再闭环

1. 让车按固定转角走，验证运动学方向对不对。
2. 给固定的目标速度，验证电机转向、编码器符号。
3. 再加横向控制器。

跳过开环直接闭环，出了问题很难定位是模型、传感器还是控制器。

### 5.2 一次只改一个参数

改三个参数，结果变好，你不知道是哪个起的作用。用 git 或表格记录每次实验。

### 5.3 记录数据

CSV 比“感觉”可靠。至少记录：

- 时间
- 位姿
- 目标值 / 实际值
- 控制输出
- 误差

仿真里已经写了。实车上用 SD 卡、无线串口或上位机。

### 5.4 先慢后快

低速调好再提速。高速下延迟、噪声、饱和都会放大。

## 6. 常见故障与定位

| 现象 | 可能原因 | 怎么查 |
|---|---|---|
| 车往一边偏 | 舵机中值不准、轮子不对称 | 直线测试，看 `delta=0` 时是否直行 |
| 越跑越偏 | 航向积分错误、轮距标定错 | 原地转 10 圈，对比航向 |
| 画龙 | 前视距离太小、P 太大、延迟 | 降增益、加滤波、加前视 |
| 弯道切内线 | 纯跟踪固有、前视太大 | 减小 `ld`、加曲率前馈 |
| 出弯回不来 | 积分饱和、舵机限幅 | 看输出是否顶满、加抗饱和 |
| 高速振 | 噪声、延迟、模型失配 | 降带宽、加滤波、增益调度 |
| 起步冲 | 积分累积、死区补偿过大 | 积分分离、斜坡起步 |
| 刹车距离不够 | `a_dec` 估大、速度太高 | 降低 `a_lat`、提前减速 |

## 7. 加一个自己的控制器

步骤：

1. 在 `include/sc/` 新建头文件，声明 `init` 和 `update`。
2. 在 `src/` 实现，状态放结构体，不做动态分配。
3. 在 `tests/test_main.c` 加数值测试。
4. 在 `sim/sim_common.h` 的 `sim_ctrl_t` 加枚举。
5. 在 `sim/sim_common.c` 的 `sim_run` 加分支。
6. 在 `sim/sim_compare.c` 加文件列表。

示例骨架：

```c
/* include/sc/my_ctrl.h */
typedef struct {
    float gain;
    float max_steer;
} sc_my_ctrl_t;

void  sc_my_ctrl_init(sc_my_ctrl_t *c, float gain, float max_steer);
float sc_my_ctrl_update(const sc_my_ctrl_t *c, float e_y, float e_psi);

/* src/my_ctrl.c */
float sc_my_ctrl_update(const sc_my_ctrl_t *c, float e_y, float e_psi) {
    float delta = -c->gain * e_y - e_psi;
    return sc_clampf(delta, -c->max_steer, c->max_steer);
}
```

然后跑测试和仿真，对比现有控制器。

## 8. 给仿真加真实感

当前仿真是理想的。想更接近实车，可以加：

1. **测量噪声**：给 `e_y`、`e_psi` 加高斯噪声。
2. **控制延迟**：控制器输出延迟 1~4 个周期。
3. **舵机动态**：一阶惯性 + 速率限制（已有速率限制）。
4. **轮胎滑移**：在积分时给 `v`、`w` 加扰动。
5. **模型失配**：控制器的 `L` 和仿真车的 `L` 不同。
6. **路面变化**：曲率突变、坡道。

加噪声后，LQR 的高增益会放大噪声，纯跟踪的鲁棒性优势会体现出来。这更接近实车。

## 9. 数据可视化

`tools/plot_sim.py` 只用标准库，不依赖 matplotlib。它做三件事：

1. 读 CSV。
2. 用纯 Python 生成 SVG。
3. 写一个 HTML 包装。

想加图，改 `main()` 里的 `draw_series` 调用即可。比如加一栏“转角 vs 时间”：

```python
series_delta = {k: col(v, "delta", 4) for k, v in runs.items()}
draw_series(svg, 640, 710, 340, 220, "前轮转角 delta (rad)",
            series_delta, "rad", tmax)
```

（需要相应调整画布高度。）

## 10. 练习

1. 把 `ld_gain` 改成 0.1，记录 RMS 和最大误差，和 0.3 对比。
2. 去掉 Stanley 的曲率前馈，重新跑，观察弯道误差。
3. 把 LQR 的 `r_delta` 从 0.15 改到 1.0，看打角是否更平滑。
4. 在仿真里加 20 ms 控制延迟（保存上一帧的 `delta_cmd`），看三种控制器谁先失稳。
5. 加一个“只按曲率限速、不做加减速扫描”的速度剖面，对比圈速和冲出赛道的情况。
