# docs 目录说明

这里分成两条线，不要混：

## 想从头学 → [00-从这里开始.md](00-从这里开始.md)

按顺序读的 12 章手册，每章都有：

- 作用
- 代码在哪（文件 + 函数 + 行号）
- 怎么用（可复制示例）
- 大白话原理
- 动手步骤
- 常见错误
- 自测

## 建议顺序

1. 打开 [00-从这里开始.md](00-从这里开始.md)
2. 读第 0 章，跑 `make test`
3. 按章往下读，每章的动手步骤必须做
4. 卡住了再翻 `专题/` 里对应的那篇
