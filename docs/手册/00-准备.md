# 第 0 章 · 准备：编译、运行、看结果

> 目标：30 分钟内，你能自己编译、跑测试、跑仿真，并且知道每个目录是干什么的。

---

## 0.1 你需要什么

- 一台能跑命令行的电脑（这台安卓设备也可以）。
- 一个 C 编译器（`cc` 或 `clang`）。
- `make`。
- Python 3（只有画图用，不装也能跑测试和仿真）。

检查：

```sh
cc --version
make --version
python3 --version
```

## 0.2 五条命令

进入工程目录：

```sh
cd /data/user/0/cc.codroid/files/home/workspace/smartcar-algo
```

| 命令 | 作用 | 什么时候用 |
|---|---|---|
| `make test` | 编译并运行 655 项单元测试 | 每次改完算法 |
| `make sim` | 跑闭环仿真，生成 CSV | 改完控制参数 |

第一次先跑：

```sh

```

最后一行应该是：

```

```

如果失败，先 `make clean` 再 `make test`。还失败，看 0.6。

## 0.3 目录地图

| 路径 | 里面是什么 | 你要不要改 |
|---|---|---|
| `README.md` | 总览、算法地图 | 不用 |
| `docs/00-从这里开始.md` | 你正在读的手册 | 不用 |
| `docs/手册/` | 手册各章 | 不用 |
| `docs/专题/` | 深入阅读的专题文档 | 需要时查 |
| `include/sc/` | 每个模块的头文件（接口、参数说明） | 看懂 |
| `src/` | 算法实现 | 要改 |
| `tests/test_main.c` | 单元测试 | 可以加 |
| `sim/` | 仿真：赛道、车辆、控制器对比 | 要改参数 |
| `experiments/` | 小实验程序 | 要改 |
| `tools/plot_sim.py` | 画图脚本 | 不用 |
| `out/` | 仿真输出（CSV、SVG、HTML） | 看结果 |
| `build/` | 编译产物 | 不用 |

**先记住两个地方**：

- 算法在 `src/`，接口在 `include/sc/`。
- 仿真参数在 `sim/sim_common.c`。

## 0.4 改代码的标准流程

每次只做这五步：

1. **改一个地方**（一个参数或一个函数）。
2. **编译**：`make test` 或 `make sim`。
3. **看结果**：测试是否通过？指标变了多少？
4. **解释**：为什么变好/变坏？
5. **记录**：写三行笔记。

不要一次改五个地方。改多了，你不知道是谁起的作用。

### 怎么改参数

打开 `sim/sim_common.c`，找到这一段：

```c
sc_pure_pursuit_t pp;
sc_pp_init(&pp, 0.33f, 0.55f, 0.30f, 0.55f);
```

第三个参数 `0.30f` 是前视距离增益。把它改成 `0.10f`，然后：

```sh
make sim
```

看输出的 `RMS ey` 和 `首圈用时` 怎么变。

### 怎么加打印

在 C 代码里加：

```c
printf("v=%.3f w=%.3f\n", (double)v, (double)w);
```

记得文件开头要有 `#include <stdio.h>`。

## 0.6 出错了怎么办

| 现象 | 先做什么 |
|---|---|
| `make: command not found` | 装 `make` |
| 编译报错 | 看第一个 error，不要看最后一个 |
| 测试失败 | 看 `FAIL 文件名:行号`，打开那一行 |
| 仿真没输出 | 先 `make clean` 再 `make sim` |
| 图打不开 | 直接打开 `out/sim_compare.svg` |
| 改了没变化 | 确认你改的是 `src/` 或 `sim/`，不是 `build/` |

**永远先看第一个错误。** 后面的错误经常是第一个引起的。
