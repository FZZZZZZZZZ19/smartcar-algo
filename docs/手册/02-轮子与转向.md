# 第 2 章 · 常用轮子与各种转向方式

> 这一章只讲两件事：**轮子有哪几种**、**车能怎么转**。
> 学完你能看着一辆车，说出它用什么轮子、能怎么转、该套哪个模型。

---

## 2.1 为什么单独讲轮子

同样是“轮子”，运动能力完全不同：

- 普通轮：只能往前滚，不能横着走。
- 万向轮：能随便转，但不能驱动。
- 麦轮：能横着走，但效率低。
- 全向轮：也能横着走，结构不一样。
- 履带：能越野，但不能横移。

**轮子决定了车的“自由度”**，也决定了你用哪套运动学公式。

## 2.2 六种常用轮子

### 2.2.1 普通橡胶轮

```
      侧视图              俯视图
      ┌─────┐              │
      │     │           ───┼───
      │  ●  │              │
      └─────┘              │
```

| 项目 | 说明 |
|---|---|
| 结构 | 圆柱形轮胎，靠胎面摩擦滚动 |
| 能驱动 | 能 |
| 能横移 | 不能（侧向靠摩擦锁住） |
| 优点 | 抓地好、承载大、便宜、效率高 |
| 缺点 | 转弯时内外轮路径不同，必须差速 |
| 典型用途 | 差速驱动轮、阿克曼前后轮 |

**关键**：普通轮转弯时，内侧轮走的圆更小。如果左右轮被一根轴硬连在一起（没有差速器），转弯会拖胎。

### 2.2.2 万向轮（Caster）

```
      侧视图
        │
      ┌─┴─┐
      │   │
      └─┬─┘
       ●    小轮可以绕竖轴 360° 转
```

| 项目 | 说明 |
|---|---|
| 结构 | 小轮 + 竖直转轴，带偏置 |
| 能驱动 | 不能，只承重 |
| 能横移 | 随动，车往哪走它往哪转 |
| 优点 | 让两轮车稳定站立，转向阻力小 |
| 缺点 | 承重过大会卡；过坎/缝隙容易别住；高速可能摆振 |
| 典型用途 | 差速车的前后支撑 |

**关键**：万向轮只负责“撑住”，不参与驱动和转向。它的好坏直接影响车能不能顺滑地原地转。

### 2.2.3 麦克纳姆轮（Mecanum）

```
      俯视图
      ┌───────────┐
      │ ◤       ◥ │   每个轮子外圈有一圈 45° 辊子
      │           │
      │ ◣       ◢ │
      └───────────┘
```

| 项目 | 说明 |
|---|---|
| 结构 | 轮毂 + 一圈与轮轴成 45° 的辊子 |
| 能驱动 | 能 |
| 能横移 | 能（四个轮子组合） |
| 优点 | 全向移动、承载比全向轮好 |
| 缺点 | 效率低、横移打滑、对地面平整度敏感、辊子易磨损 |
| 典型用途 | 麦轮组 |

**关键**：

- 左右轮的辊子**镜像安装**。装反了，横移方向会反。
- 四个轮子必须**同时着地**。有一个悬空，车就往一边跑。
- 横移时辊子打滑，里程计不准。

### 2.2.4 全向轮（Omni）

```
      俯视图
      ┌───────────┐
      │     ○     │   轮缘一圈小滚子
      │           │   滚子轴线垂直于轮平面
      │ ○       ○ │
      └───────────┘
```

| 项目 | 说明 |
|---|---|
| 结构 | 轮毂 + 轮缘一圈小滚子 |
| 能驱动 | 能 |
| 能横移 | 能（三个轮子 120° 组合） |
| 优点 | 效率比麦轮高、结构简单 |
| 缺点 | 三轮布局承载/越障一般；安装角精度要求高 |
| 典型用途 | 全向组（120° 三轮） |

**关键**：全向轮和麦轮都能横移，但原理不同：

- 麦轮：辊子斜 45°，靠斜向分力。
- 全向轮：滚子垂直于轮平面，轮子能横向“滑过去”。

### 2.2.5 履带

```
      侧视图
      ┌─────────────┐
      │  ████████   │
      │ ██      ██  │
      └─────────────┘
```

| 项目 | 说明 |
|---|---|
| 结构 | 环形履带 + 驱动轮/导向轮 |
| 能驱动 | 能 |
| 能横移 | 不能 |
| 优点 | 接地比压小、越野强、抓地好 |
| 缺点 | 转向阻力大、磨损快、效率低、不能横移 |
| 典型用途 | 越野、特殊地形 |

转向方式和差速一样：左右履带速度差。

### 2.2.6 舵轮（Steering Wheel）

```
      俯视图
      ┌───────────┐
      │  ◎     ◎  │   每个模块 = 转向电机 + 驱动电机 + 轮子
      │           │
      │  ◎     ◎  │
      └───────────┘
```

| 项目 | 说明 |
|---|---|
| 结构 | 转向电机 + 驱动电机 + 轮子，模块化 |
| 能驱动 | 能 |
| 能横移 | 能（每个轮子独立转向） |
| 优点 | 全向、承载大、控制灵活 |
| 缺点 | 复杂、贵、控制难度高 |
| 典型用途 | AGV、工业机器人 |

智能车比赛里少见，但工业上很常用。

### 2.2.7 平衡轮组

```
        ●  重心
        │
   ██       ██   同轴两轮
```

两个同轴轮 + 高重心车身。不能静态站立，必须靠控制保持平衡。转向靠左右轮速差。

## 2.4 五种转向/移动方式

### 2.4.1 差速转向

```
直行：    ●──●        左转：   ●──●
          vl=vr                vl<vr
```

| 动作 | 条件 | 说明 |
|---|---|---|
| 直行 | `v_l = v_r` | 车体不转 |
| 圆弧转 | `v_l ≠ v_r`，`v ≠ 0` | 边走边转 |
| 原地转 | `v_l = -v_r`，`v = 0` | 绕车体中心转 |

公式：

```
v = (v_l + v_r) / 2
w = (v_r - v_l) / L
```

- 最小转弯半径：**0**（可以原地转）。
- 代码：第 3 章，`sc_diff_*`。

### 2.4.2 阿克曼转向

```
        ↙       ↘        前轮转角 delta
   ██             ██     后轮驱动
```

公式：

```
R = L / tan(delta)
```

- 前轮转角越大，半径越小。
- 最小转弯半径：`R_min = L / tan(delta_max)`。
- **不能原地转**，也不能横移。
- 内外轮转角不同，见第 4 章。

### 2.4.3 麦轮移动

四个轮子组合，能做出这些动作：

| 动作 | 四个轮子怎么转 |
|---|---|
| 前进 | 四个同向 |
| 后退 | 四个反向 |
| 左移 | 左前/右后反转，右前/左后正转（以实际接线为准） |
| 右移 | 与左移相反 |
| 原地左转 | 左侧两轮反转，右侧两轮正转 |
| 原地右转 | 相反 |
| 斜行 | 前进 + 横移的组合 |

公式和代码：第 3 章，`sc_mecanum_*`。

### 2.4.4 全向三轮移动

三个轮子间隔 120°，通过三个速度组合，可以实现：

- 任意方向平移。
- 原地旋转。
- 平移 + 旋转同时进行。

公式和代码：第 3 章，`sc_omni3_*`。

### 2.4.5 平衡车转向

- 直立：靠前后加速/减速保持平衡。
- 转向：左右轮差速。
- 不能静态站立，停车也要控制。

公式和代码：第 3 章，`sc_balance_*`。

## 2.5 不同场景怎么转

### 2.5.1 直角弯

| 车型 | 怎么过 |
|---|---|
| 阿克曼 | 外-内-外：入弯前靠外，弯心贴内，出弯回外；提前减速、提前打角，不能原地转 |
| 差速 | 可以原地转，但比赛通常保持速度走圆弧，内侧轮容易打滑 |
| 麦轮/全向 | 可以横移 + 转，贴更紧的内线 |

### 2.5.2 环岛

| 车型 | 怎么过 |
|---|---|
| 阿克曼 | 沿圆弧走，注意内外轮差速和速度；入环/出环要提前判断 |
| 差速 | 可以更小半径，注意内侧轮打滑 |
| 麦轮/全向 | 可以保持车头方向横移绕行（少见，效率低） |

### 2.5.3 窄路掉头

| 车型 | 怎么掉头 |
|---|---|
| 阿克曼 | **三点掉头**：前进左打满 → 倒车右打满 → 前进回正 |
| 差速 | 原地转（`v_l = -v_r`） |
| 麦轮/全向 | 原地转，或横移 + 转 |

### 2.5.4 侧方停车 / 贴边

| 车型 | 怎么停 |
|---|---|
| 阿克曼 | 需要多次前后挪，不能直接横移 |
| 差速 | 不能横移，只能前后 + 原地转调整 |
| 麦轮/全向 | 直接横移贴边，最方便 |

### 2.5.5 高速弯

| 车型 | 怎么走 |
|---|---|
| 阿克曼 | 外-内-外，用满赛道宽度；注意重心转移和轮胎极限 |
| 差速 | 靠速度差，内侧轮容易打滑，速度受限 |
| 麦轮 | 高速横移效率低，一般不用 |

### 2.5.6 低速对齐 / 微调

| 车型 | 怎么调 |
|---|---|
| 麦轮/全向 | 横移 + 原地转，最快 |
| 差速 | 原地转 + 前后挪 |
| 阿克曼 | 多次前后挪，最慢 |

## 2.6 一张表：场景 × 车型

| 场景 | 阿克曼 | 差速 | 麦轮/全向 |
|---|---|---|---|
| 直角弯 | 外-内-外 | 圆弧/原地转 | 横移+转 |
| 环岛 | 沿圆弧 | 小半径圆弧 | 可横移 |
| 窄路掉头 | 三点掉头 | 原地转 | 原地转/横移 |
| 侧方停车 | 多次挪 | 多次挪 | 直接横移 |
| 高速弯 | 最优 | 受打滑限制 | 不适用 |
| 低速微调 | 慢 | 中 | 快 |

## 2.7 动手步骤

### 步骤 1：认轮子

看你的车（或网上找一辆比赛车的照片），回答：

- 几个轮子？
- 哪几个能驱动？
- 哪几个能转向？
- 轮子表面有没有辊子/小滚子？
- 有没有万向轮？

### 步骤 2：画自由度

在纸上画：

```
能前进？  能后退？  能横移？  能原地转？
```

四个问题，对应你的车。

### 步骤 3：选模型

对照第 1 章 1.3 的表，写下你的车用哪个模型。

### 步骤 4：算一次

- 差速：`v_l=0.5, v_r=1.5, L=1`，算 `v` 和 `w`。
- 阿克曼：`L=0.3, delta=0.3`，算半径 `R`。
- 麦轮：`vx=0.5, vy=0.2, wz=0`，算四个轮子速度（用第 3 章公式）。

找到 `-- kinematics`，对照你的模型看测试是否全过。

## 2.8 常见错误

| 错误 | 后果 | 怎么改 |
|---|---|---|
| 普通轮当麦轮 | 横移根本走不了 | 先认轮子 |
| 麦轮左右装反 | 横移方向反、原地打转 | 检查辊子镜像 |
| 全向轮角度不准 | 走直线偏 | 重新定位 120° |
| 阿克曼想原地转 | 做不到，轮胎拖 | 用三点掉头 |
| 差速原地转时万向轮卡住 | 转不动/抖动 | 检查万向轮承重和间隙 |
| 履带当轮式算 | 转向阻力没考虑 | 用差速模型但留更大余量 |
| 四轮普通轮当差速 | 后轮不能转向，转弯拖 | 用阿克曼或加万向轮 |

## 2.9 自测

1. 哪两种轮子能横移？
2. 万向轮能驱动吗？它的作用是什么？
3. 麦轮横移时，四个轮子大致怎么转？
4. 阿克曼的最小转弯半径怎么算？
5. 差速车原地转的条件是什么？
6. 窄路掉头，阿克曼车怎么做？
7. 侧方停车，哪种车最方便？
8. 为什么麦轮左右要镜像安装？

答案：

1. 麦克纳姆轮、全向轮（舵轮也能）。
2. 不能；只承重、随动，让两轮车稳定站立。
3. 对角线两轮同向、另一对反向（左右两侧形成横向分力）。
4. `R_min = L / tan(delta_max)`。
5. `v_l = -v_r`，车体线速度为 0。
6. 三点掉头：前进左打满 → 倒车右打满 → 前进回正。
7. 麦轮/全向车，直接横移。
8. 左右轮辊子旋向相反，横向分力才能同向叠加。

全对，进入第 3 章。
