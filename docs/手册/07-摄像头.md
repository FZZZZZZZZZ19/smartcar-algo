## 5.1 它是干什么的

摄像头巡线的任务：**从一张图像里，找出赛道的中线，算出车相对中线的偏差。**

流程：

```
灰度图 → 二值化 → 找边线 → 算中线 → 算曲率 → 识别元素
```

## 5.3 怎么用（最小流程）

```c
#include "sc/camera_line.h"

/* 假设你已经有了一帧灰度图 */
uint8_t gray[160 * 120];
sc_image_t img = {gray, 160, 120};

/* 1. 自动阈值 + 二值化（黑线=1） */
uint8_t th = sc_otsu(&img);
uint8_t bin[160 * 120];
sc_binarize(&img, bin, th, 1);   /* 1 = 线是暗的 */

/* 2. 从底部向上扫边线 */
sc_edge_t e;
sc_scan_edges(bin, 160, 120,
              119,   /* 从最后一行开始 */
              -1,    /* 每次往上走一行 */
              60,    /* 扫 60 行 */
              80,    /* 底部种子列，一般 width/2 */
              5,     /* 每行最大横向跳变 */
              5,     /* 最小赛道宽度 */
              &e);

/* 3. 取底部中线 */
if (e.center[0] >= 0) {
    int center = e.center[0];
    int error_px = center - 80;   /* 相对图像中心 */
}
```

## 5.4 大白话原理

### 二值化

灰度图有 0~255 个亮度。二值化就是**一刀切**：

```
比阈值暗 → 1（线）
比阈值亮 → 0（背景）
```

阈值怎么定？最常用**大津法（Otsu）**：找一个让“黑的和白的分得最开”的数。

代码里有个细节：判断暗像素用 `<=` 而不是 `<`。因为 Otsu 可能正好返回暗峰的亮度，用 `<` 会把整条线判成背景，图像直接翻转。

### 八邻域爬线

从线底部一个点出发，看周围 8 个格子，哪个是线就走过去，一直爬到顶部。

```
7 0 1
6 ● 2
5 4 3
```

搜索顺序优先“直行”，再左右偏，避免 1 像素细线左右抖。

适合**单根线**。赛道是两条边线时，用下面的逐行扫描。

### 逐行扫边线

从图像底部往上，一行一行找：

1. 从上一行的中心附近开始。
2. 向左右扩展，直到不是赛道。
3. 记下左边界、右边界、宽度。
4. 下一行从这一行的中心开始。

`max_jump` 限制每行最多横向跳多少像素，防止在十字路口跳到另一条边。

### 曲率

取中线上三个点，算它们外接圆的半径：

```
曲率 = 1 / 半径
```

半径越小，弯越急。

**注意**：三点不能离太近。三点几乎在一条直线上时，浮点误差会把曲率算飞。经验上间隔至少 0.2~0.3 m。

### IPM 逆透视

摄像头是斜着拍的，近处宽、远处窄。IPM 把图像“摊平”成俯视图，这样算出来的距离和曲率才是真实物理量。

```c
sc_camera_t cam;
sc_camera_init(&cam,
               0.5f,                    /* 相机离地高度 m */
               10.0f * SC_DEG2RAD,      /* 向下俯仰角 */
               200.0f,                  /* 焦距（像素） */
               80.0f, 60.0f             /* 主点 */
               );

float gx, gy;
sc_ipm_pixel_to_ground(&cam, u, v, &gx, &gy);
/* gx 向前，gy 向左，单位 m */
```

## 5.6 常见错误

| 错误 | 现象 | 怎么改 |
|---|---|---|
| 阈值方向反了 | 整张图全白/全黑 | 检查 `line_is_dark` |
| 用 `<` 不用 `<=` | 图像翻转 | 用 `<=` |
| `max_jump` 太小 | 大弯丢线 | 增大 |
| `max_jump` 太大 | 十字跳线 | 减小 |
| 曲率三点太近 | 曲率乱跳 | 增大间隔或用拟合 |
| 没做 IPM | 曲率不是物理量 | 先转地面坐标 |
| 只用图像上半部分 | 远端噪声大 | 只扫下半部分 |

## 5.7 自测

1. 二值化解决什么问题？
2. Otsu 在找什么？
3. 八邻域爬线适合什么场景？不适合什么场景？
4. `max_jump` 太大和太小分别会怎样？
5. 为什么像素曲率不能直接拿去做速度规划？
6. IPM 需要哪几个相机参数？

答案：

1. 把灰度图变成“线/背景”两种，方便找边界。
2. 让两类像素分得最开的阈值。
3. 适合单根线；不适合两条边线的赛道（会分叉）。
4. 太大跨到别的线；太小学不会大弯。
5. 透视会让远处的一小段在图像上很长，不是真实曲率。
6. 高度、俯仰角、焦距、主点。
