# 第 4 章 · 路径跟踪：纯跟踪、Stanley、LQR

> 学完这一章，你能回答：车偏离路径时，方向盘该打多少？三种方法各看什么？为什么纯跟踪会切内线？

---

## 4.1 它是干什么的

路径跟踪解决一个问题：

> 已知一条参考路径，车现在有偏差，怎么打方向把车拉回去？

它输出的是**前轮转角 `delta`**，然后交给舵机。

---

## 4.2 先理解两个误差

文件：`src/path.c`

| 功能 | 函数 | 行号 |
|---|---|---|
| 建路径 | `sc_path_build` | 22 |
| 投影到路径 | `sc_path_project` | 141 |
| 按弧长取点 | `sc_path_point_at` | 66 |
| 前视点 | `sc_path_lookahead` | 229 |
| 曲率 | `sc_path_curvature_at` | 124 |

最重要的函数是投影：

```c
float s, e_y, e_psi;
int idx;

sc_path_project(&path, pose.x, pose.y, pose.theta,
                hint, 40, &s, &e_y, &e_psi, &idx);
```

输出三个关键量：

| 量 | 意思 | 正方向 |
|---|---|---|
| `s` | 车在路径上的位置（走了多远） | 沿路径增加 |
| `e_y` | 横向误差 | 车在路径**左侧**为正 |
| `e_psi` | 航向误差 | 车头相对路径**左偏**为正 |

记住 `e_y` 的符号：**正 = 车在左边**。控制器要把 `e_y` 拉回 0，所以左偏时要右打（负转角）。

## 4.3 纯跟踪 Pure Pursuit

代码：`src/pure_pursuit.c`

| 功能 | 函数 | 行号 |
|---|---|---|
| 初始化 | `sc_pp_init` | 5 |
| 前视距离 | `sc_pp_lookahead` | 15 |
| 算转角 | `sc_pp_steer` | 30 |

### 大白话

你走路时不会盯着脚下，而是**盯着前方几米的一个点**，朝那个点走。纯跟踪就是让车盯着路径上的一个前视点。

- 前视点近：贴线紧，但容易左右摆。
- 前视点远：平滑，但弯道会“切内线”。

### 怎么用

```c
sc_pure_pursuit_t pp;
sc_pp_init(&pp,
           0.33f,  /* 轴距 L */
           0.55f,  /* 前视距离基数 */
           0.30f,  /* 随速度增加的增益 */
           0.55f   /* 最大转角 */
           );

float ld = sc_pp_lookahead(&pp, v);   /* ld = base + gain·v */

float tx, ty;
sc_path_lookahead(&path, s, ld, &tx, &ty, NULL);

float delta = sc_pp_steer(&pp, &pose, tx, ty);
```

### 原理（一句话）

车到前视点的连线，和车头方向有一个夹角 `alpha`。车要沿着一段圆弧走到前视点：

```
delta = atan(2·L·sin(alpha) / ld)
```

不用背，知道“前视点越远，打角越保守”就够了。

## 4.4 Stanley

代码：`src/stanley.c`

| 功能 | 函数 | 行号 |
|---|---|---|
| 初始化 | `sc_stanley_init` | 5 |
| 设置轴距 | `sc_stanley_set_wheelbase` | 13 |
| 经典版 | `sc_stanley_steer` | 17 |
| 带曲率前馈 | `sc_stanley_steer_ff` | 26 |

### 大白话

纯跟踪只看前视点。Stanley 同时看两件事：

1. **车头朝向对不对**（航向误差 `e_psi`）。
2. **车离中线多远**（横向误差 `e_y`）。

```
delta = -e_psi - atan(k · e_y / (|v| + soft))
```

- 车头左偏（`e_psi>0`）→ 右打。
- 车在左边（`e_y>0`）→ 右打。
- 速度越低，第二项越强（分母加 `soft` 防止爆炸）。

### 为什么要加曲率前馈

经典 Stanley 在弯道上会有一个稳态误差：它总要“先偏出去”，才能产生修正。

加一项：

```
delta += atan(L · kappa)
```

弯道还没偏，就先把方向打过去。仿真里误差从 **0.12 m** 降到 **0.0004 m**。

### 怎么用

```c
sc_stanley_t st;
sc_stanley_init(&st, 2.0f, 0.45f, 0.55f);
sc_stanley_set_wheelbase(&st, 0.33f);

float delta = sc_stanley_steer_ff(&st, v, e_y, e_psi, kappa);
```

## 4.5 LQR

代码：`src/lqr.c`、`src/linalg.c`

| 功能 | 函数 | 行号 |
|---|---|---|
| 初始化 | `sc_lqr_track_init` | 6 |
| 速度变了重算 | `sc_lqr_track_rebuild` | 20 |
| 算转角 | `sc_lqr_track_update` | 58 |

### 大白话

LQR 像一个**会计**：

- 横向误差 `e_y` 有成本。
- 航向误差 `e_psi` 有成本。
- 打方向 `delta` 也有成本。

它找一组反馈系数，让“总成本”最小。

```
delta = -k_y · e_y - k_psi · e_psi + atan(L · kappa)
```

`k_y`、`k_psi` 不是手调的，是解出来的。你调的是三个权重：

| 参数 | 调大后 |
|---|---|
| `q_y` | 更在意横向误差，打角更积极 |
| `q_psi` | 更在意航向，转弯更平顺 |
| `r_delta` | 更在意打角代价，输出更保守 |

### 怎么用

```c
sc_lqr_track_t lqr;
sc_lqr_track_init(&lqr,
                  0.33f,   /* 轴距 */
                  1.0f,    /* 当前速度 */
                  0.005f,  /* 控制周期 */
                  1.0f,    /* q_y */
                  1.5f,    /* q_psi */
                  0.15f,   /* r_delta */
                  0.55f    /* 最大转角 */
                  );

float delta = sc_lqr_track_update(&lqr, e_y, e_psi, kappa);
```

**注意**：`K` 和速度有关。速度变化大时要重算：

```c
if (fabsf(v - lqr.v) > 0.4f) {
    sc_lqr_track_rebuild(&lqr, v);
}
```

## 4.6 预瞄控制（了解）

代码：`src/preview.c`

先预测“再过 0.4 秒车会到哪”，把预测点投影到路径上，再用 PD：

```
delta = -k_y · e_y_preview - k_psi · e_psi + 前馈
```

它介于纯跟踪和 LQR 之间：比纯跟踪好调，比 LQR 依赖模型少。

---

## 4.7 三种方法对比

仿真结果（同一辆车、同一条赛道、5 ms 周期）：

| 控制器 | RMS 横向误差 | 最大误差 |
|---|---:|---:|
| 纯跟踪 | 0.0300 m | 0.0906 m |
| Stanley + 前馈 | 0.0004 m | 0.0018 m |
| LQR + 前馈 | 0.0009 m | 0.0029 m |

怎么选：

- **纯跟踪**：最简单、最皮实，弯道会切内线。
- **Stanley**：低速贴线好，对噪声敏感，建议加前馈。
- **LQR**：理论最优，但依赖模型、要调权重、要做增益调度。

## 4.9 常见错误

| 错误 | 后果 | 怎么改 |
|---|---|---|
| `e_y` 符号反了 | 越修越偏 | 记住：左正右负 |
| 参考点不一致 | 恒定偏移 | 控制器和定位都用后轴 |
| 前视距离太小 | 画龙 | 增大 `ld_base` |
| 前视距离太大 | 切内线 | 减小 `ld_base` |
| Stanley 没前馈 | 弯道稳态误差 | 用 `_ff` 版本 |
| LQR 不调度 | 高速失稳 | 速度变化超过 0.4 m/s 重算 |
| 没有舵机限速 | 打角冲击 | 加 `sc_slew_limit` |

## 4.10 自测

1. `e_y > 0` 表示车在路径哪一侧？应该左打还是右打？
2. 纯跟踪前视距离变大，切内线更严重还是更轻？
3. Stanley 的两项分别修正什么？
4. 为什么 Stanley 加曲率前馈后误差大幅下降？
5. LQR 的 `q_y` 调大会怎样？
6. 为什么 LQR 要做增益调度？

答案：

1. 左侧；右打（负转角）。
2. 更严重。
3. 航向误差、横向误差。
4. 弯道还没产生偏差就提前打角，消除稳态误差。
5. 更在意横向误差，打角更积极，误差更小但可能更抖。
6. `K` 和速度有关，速度变了最优增益也变。
