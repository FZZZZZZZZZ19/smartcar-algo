---

## 1.1 它是干什么的

差速驱动是智能车最基础的运动方式：**左右两个轮子（或两组轮子）各转各的，靠转速差转弯。**

它用在：双电机三轮车、履带车、平衡车的轮组、部分四驱车。

---

## 1.2 先建立坐标直觉

```
        y（左）
        ↑
        │
        │        车头
        │       ↗
        │     θ
        └──────────→ x（前）
```

| 符号 | 意思 | 正方向 |
|---|---|---|
| `theta` | 车头朝向 | 逆时针 |
| `v` | 前进速度 | 向前 |
| `w` | 转弯角速度 | 向左转 |
| `delta` | 前轮转角 | 向左打 |

**为什么先讲坐标**：后面所有误差、控制器、传感器都依赖这套符号。符号反了，车会往反方向修正，越跑越偏。

## 1.4 怎么用

### 第一步：初始化

```c
sc_diff_drive_t car;
sc_diff_init(&car,
             0.05f,   /* 轮子半径 r，单位 m */
             1.00f,   /* 轮距 L，左右轮中心距，单位 m */
             1.0f,    /* 减速比：电机转几圈 = 车轮转一圈 */
             1000.0f  /* 编码器每圈计数（四倍频后） */
             );
```

### 第二步：轮速和车体速度互算

```c
float v, w;

/* 左轮 0.5 m/s，右轮 1.5 m/s，轮距 1 m */
sc_diff_forward(&car, 0.5f, 1.5f, &v, &w);
/* 结果：v = 1.0, w = 1.0 */

/* 反过来：想以 1 m/s 直行 */
float vl, vr;
sc_diff_inverse(&car, 1.0f, 0.0f, &vl, &vr);
/* 结果：vl = 1.0, vr = 1.0 */
```

### 第三步：编码器算速度

```c
/* 这 1 秒内某个轮子走了 1000 个计数 */
float wheel_speed = sc_diff_wheel_speed(&car, 1000, 1.0f);
/* 1000 计数 = 1 圈 = 2π×0.05 = 0.314 m，所以约 0.314 m/s */
```

### 第四步：更新位姿

```c
sc_pose2_t pose = {0.0f, 0.0f, 0.0f};  /* x, y, theta */

/* 每 1 ms 调用一次 */
sc_diff_odometry(&pose, &car, 0.5f, 1.5f, 0.001f);
```

## 1.5 大白话原理

把车想成**坦克**：

- 左右轮一样快 → 直行。
- 左轮慢、右轮快 → 向右转？不对，是**向左转**。
  因为右边走得远，车头被推向左。
- 左轮反转、右轮正转 → 原地打转。

用公式说：

```
车体速度 = 两个轮子的平均速度
转弯速度 = 两个轮子的速度差 ÷ 轮距
```

```
v = (v_l + v_r) / 2
w = (v_r - v_l) / L
```

反过来：

```
v_l = v - w·L/2
v_r = v + w·L/2
```

**轮距 L 是什么**：左右轮**中心**之间的距离。不是车宽，不是轮子外缘距离。这是新手最常错的地方。

## 1.6 航迹推算：为什么不能简单累加

最直觉的写法：

```c
x += v * cos(theta) * dt;
y += v * sin(theta) * dt;
theta += w * dt;
```

这叫**欧拉积分**。直线时没问题，但转弯时它会算错：车实际走的是圆弧，欧拉把它当成“先直走一小段，再瞬间转一点”。

正确做法是圆弧积分：

```
半径 R = v / w
转角 dθ = w · dt
x += R·(sin(θ+dθ) - sinθ)
y += -R·(cos(θ+dθ) - cosθ)
θ += dθ
```

代码里的 `sc_diff_odometry` 就是这么做的：

```c
float r = v / w;
float dtheta = w * dt;
pose->x += r * (sinf(theta1) - sinf(theta0));
pose->y += -r * (cosf(theta1) - cosf(theta0));
```

**验证方法**：让 `v=1, w=1`，走 `2π` 秒。车应该绕半径 1 m 的圆走一圈，回到原点。欧拉积分回不去，圆弧积分能回去。

## 1.8 常见错误

| 错误 | 后果 | 怎么改 |
|---|---|---|
| 把车宽当轮距 | 转弯半径算错，航向漂 | 量左右轮中心距 |
| 编码器 PPR 没乘 4 | 速度只有真实的 1/4 | 正交编码器四倍频 |
| 左右轮方向反了 | 直行变原地转 | 手推车前进，两个轮速都应为正 |
| 角度没归一化 | theta 越加越大，cos/sin 精度下降 | 用 `sc_wrap_pi` |
| 用欧拉积分 | 转弯后位置漂 | 用圆弧积分 |

## 1.9 自测

1. `v_l=0.2, v_r=0.8, L=0.4`，求 `v` 和 `w`。
2. 想以 `v=0.5, w=-1` 行驶，左右轮速度各是多少？
3. 轮距从 1 m 改成 0.5 m，同样的轮速差，转弯角速度变大还是变小？
4. 为什么欧拉积分画圆回不到原点？
5. 编码器 1000 线，四倍频后 PPR 是多少？

答案：

1. `v=0.5`，`w=1.5`。
2. `v_l = 0.5 - (-1)×0.2 = 0.7`，`v_r = 0.5 + (-1)×0.2 = 0.3`。
3. 变大（`w = Δv/L`，L 变小，w 变大）。
4. 它把圆弧当成折线，每步都少走一点弧长，误差累积。
5. 4000。
