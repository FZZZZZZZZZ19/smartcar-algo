## 6.1 它是干什么的

赛道上铺一根通交流电的导线，车上装几个电感线圈。**离导线越近，感应电压越大。**

电磁巡线的任务：**从几个电压值，算出车相对导线的横向偏移。**

优点：不受光照影响、帧率高、便宜。
缺点：信息少，元素识别更依赖布局和状态机。

## 6.3 怎么用（五电感）

```c
#include "sc/emag.h"

/* 从左到右，左正右负。索引 0 是最左边 */
float pos[5] = {0.16f, 0.08f, 0.0f, -0.08f, -0.16f};

sc_emag_t em;
sc_emag_init(&em, 5, pos, 100.0f);   /* 100 = 初始最大值 */

/* 每帧读 ADC */
float raw[5] = {120.0f, 860.0f, 1500.0f, 700.0f, 90.0f};
sc_emag_update(&em, raw);

/* 归一化后的值在 em.norm[0..4]，范围 0~1 */
float offset = sc_emag_offset_5(&em, 0.2f);
/* 正 = 导线在左，负 = 导线在右 */
```

三电感用二次拟合：

```c
float p3[3] = {-0.05f, 0.0f, 0.05f};
float v3[3] = {em.norm[0], em.norm[1], em.norm[2]};
float offset = sc_emag_quadratic_offset(p3, v3);
```

## 6.4 大白话原理

### 为什么要归一化

原始 ADC 受这些影响：

- 电池电压（8.4 V 掉到 7.0 V，读数整体变小）
- 温度
- 赛道电流
- 线圈高度、个体差异

归一化：

```
归一化值 = (原始值 - 最小值) / (最大值 - 最小值)
```

最大值不是固定的，而是“曾经到过的峰值”，然后慢慢衰减。车经过导线正上方时刷新峰值，离开后不会立刻掉下来。

### 差比和

两个电感，左 `L`、右 `R`：

```
ratio = (L - R) / (L + R)
```

**为什么好**：如果电压和距离成反比，

```
L = k / (d + 偏移)
R = k / (d - 偏移)
```

代进去，`k` 被约掉了，只剩偏移和 `d` 的关系：

```
(L - R) / (L + R) ≈ 偏移 / d
```

所以电池电压、赛道电流变化都不影响结果。

**局限**：正中间时分母很小，噪声被放大；偏太远时一侧饱和。

### 二次拟合

三个点 `(位置, 电压)`，拟合一条抛物线：

```
y = a·x² + b·x + c
```

抛物线的顶点就是导线位置：

```
x* = -b / (2a)
```

什么时候失效：三点几乎在一条直线上（`a≈0`），顶点公式会爆炸。代码里会退化成加权质心。

### 五个电感

常用做法是分左右两组：

```
左 = norm[0] + norm[1]
右 = norm[3] + norm[4]
ratio = (左 - 右) / (左 + 右)
offset = 半宽 × tanh(2 × ratio)
```

中间的 `norm[2]` 可以判断导线是否在正中间。

### 竖直电感

车头前方的竖直电感，用来判断导线在前还是在后：

```
方向 = (上 - 下) / (上 + 下)
```

正 = 导线偏前。辅助识别环岛、十字、坡道。

```c
for (int i = 0; i < 5; i++) {
    raw[i] = 1000.0f * sc_emag_sim_field(pos[i], 0.05f, 0.05f);
}
```

导线在 `0.05 m`（偏左），看五种解算谁最接近 0.05。

- 真实偏移

- 加权质心算出来的

画成三条曲线，看谁线性最好、谁在边缘饱和。

把 `em.max_decay` 从 `0.999` 改成 `0.9`，再扫一遍。观察弯道上归一化值是否开始波动。

## 6.6 常见错误

| 错误 | 现象 | 怎么改 |
|---|---|---|
| 没归一化 | 电池一掉压，偏移全变 | 先归一化再解算 |
| 最大值衰减太快 | 弯道读数忽大忽小 | `decay` 调大 |
| 电感位置顺序反了 | 偏移符号反 | 左正右负，索引从左到右 |
| 二次拟合三点共线 | 偏移乱飞 | 检查 `a≈0`，回退质心 |
| 先归一化后滤波 | 噪声被记进最大值 | 先滤波再归一化 |
| 线圈高度不一致 | 左右不对称 | 机械调平或软件补偿 |

## 6.7 自测

1. 为什么电磁读数必须先归一化？
2. 差比和为什么能消掉绝对场强？
3. 差比和在什么位置最不准？
4. 二次拟合什么时候会失效？
5. 五个电感怎么快速算偏移？
6. 竖直电感用来干什么？

答案：

1. 电池电压、温度、赛道电流都会让原始值整体变化。
2. 分子分母都含同一个比例系数，约掉了。
3. 导线在正中间时，分母接近 0。
4. 三点近似共线，`a≈0`。
5. 左右两组求和，再做差比和。
6. 判断导线在前还是在后，辅助元素识别。
