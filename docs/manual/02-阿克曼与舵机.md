# 第 2 章 · 阿克曼转向与舵机

> 学完这一章，你能回答：前轮打多少度，车转多大弯？为什么内外轮角度不一样？舵机 PWM 怎么和角度对应？

---

## 2.1 它是干什么的

阿克曼转向是**前轮转向、后轮驱动**的车转向方式。智能车的摄像头组、电磁组、越野组基本都是这种结构。

它解决两个问题：

1. 给定前轮转角，车会走多大半径的弯？
2. 左右前轮在弯里应该各转多少度？

## 2.3 怎么用

### 初始化一辆车

```c
sc_ackermann_t car;
sc_ackermann_init(&car,
                  0.30f,  /* 轴距 L：前后轴距离，m */
                  0.20f,  /* 轮距 W：左右前轮中心距，m */
                  0.55f   /* 前轮最大转角，rad，约 31.5° */
                  );
```

### 曲率和转角互算

```c
/* 想要半径 1 m 的左弯，曲率 = 1/1 = 1 */
float delta = sc_ackermann_steer_from_curvature(&car, 1.0f);
/* delta = atan(0.3 × 1) ≈ 0.291 rad */

/* 反过来：前轮左打 0.291 rad，曲率是多少 */
float kappa = sc_ackermann_curvature(&car, delta);
/* 约等于 1.0，也就是半径 1 m */
```

### 内外轮

```c
float inner, outer;
sc_ackermann_wheel_angles(&car, 0.3f, &inner, &outer);
/* 左转时：inner > 0.3 > outer > 0 */
```

### 更新位姿

```c
sc_pose2_t pose = {0.0f, 0.0f, 0.0f};

for (int i = 0; i < 1000; i++) {
    sc_ackermann_integrate(&pose, &car, 1.0f, 0.0f, 0.001f);
}
/* 1 秒后，车前进 1 m，方向不变 */
```

## 2.4 大白话原理

### 自行车模型

把车想成一辆**自行车**：

- 后轮固定在车架上，只负责前进。
- 前轮可以转，转多少决定车的转弯半径。

前轮转得越狠，转弯半径越小：

```
R = 轴距 L / tan(前轮转角 delta)
```

比如轴距 0.3 m，前轮打 0.3 rad：

```
R = 0.3 / tan(0.3) ≈ 0.3 / 0.309 ≈ 0.97 m
```

### 为什么内外轮不一样

转弯时，**内侧轮走的圆更小**。如果两个前轮转一样多，内侧轮会侧滑。

所以：

```
内轮转角 = atan(L / (R - W/2))
外轮转角 = atan(L / (R + W/2))
```

左转时左轮是内轮，所以左轮转得更多。

阿克曼条件（可以记这个）：

```
cot(外轮) - cot(内轮) = 轮距 W / 轴距 L
```

### 舵机

舵机不懂“弧度”，只懂 PWM 脉宽。所以需要一个映射：

```
pwm = 中值 + k1 × delta + k2 × delta²
```

- 中值：车轮正前方时的 PWM，常见 1500 us。
- k1：每弧度多少 us。
- k2：补偿连杆非线性，没有就填 0。

代码：

```c
sc_servo_t servo;
sc_servo_init(&servo,
              1500.0f,  /* 中值 PWM */
              500.0f,   /* 每弧度 500 us */
              0.0f,     /* 二次项先填 0 */
              1000.0f,  /* 最小 PWM */
              2000.0f,  /* 最大 PWM */
              5.0f      /* 最大角速度 rad/s，防打坏舵机 */
              );

float pwm = sc_servo_update(&servo, delta_cmd, dt);
```

## 2.5 动手步骤

### 步骤 1：手算

已知 `L=0.3, W=0.2, delta=0.3`：

```
R = 0.3 / tan(0.3) = 0.970 m
R内 = 0.970 - 0.1 = 0.870
R外 = 0.970 + 0.1 = 1.070

内轮 = atan(0.3 / 0.870) = 0.332 rad
外轮 = atan(0.3 / 1.070) = 0.273 rad
```

### 步骤 2：和代码对比

`make test` 里的 `test_kinematics` 会检查 `inner > 0.3 > outer`。
如果你想看具体数值，在测试里加一行：

```c
printf("inner=%.4f outer=%.4f\n", (double)inner, (double)outer);
```

### 步骤 3：画一个圆

新建 `scratch/circle.c`：

```c
#include <stdio.h>
#include "sc/kinematics.h"

int main(void) {
    sc_ackermann_t car;
    sc_ackermann_init(&car, 0.30f, 0.20f, 0.55f);

    sc_pose2_t p = {0.0f, 0.0f, 0.0f};
    float delta = sc_ackermann_steer_from_curvature(&car, 0.5f);
    /* 曲率 0.5，半径 2 m */

    for (int i = 0; i < 4000; i++) {
        sc_ackermann_integrate(&p, &car, 1.0f, delta, 0.001f);
    }

    printf("x=%.3f y=%.3f theta=%.3f\n", (double)p.x, (double)p.y,
           (double)p.theta);
    return 0;
}
```

编译：

```sh
cc -std=c11 -Iinclude scratch/circle.c src/*.c -lm -o scratch/circle
./scratch/circle
```

走 4 秒、速度 1 m/s、半径 2 m，应该正好走一个圆，回到原点附近。

### 步骤 4：改最大转角

把 `sc_ackermann_init` 的 `0.55f` 改成 `0.10f`，再跑。看 `sc_ackermann_steer_from_curvature` 是否把曲率 0.5 的请求限幅了。

## 2.6 常见错误

| 错误 | 后果 | 怎么改 |
|---|---|---|
| 轴距和轮距填反 | 转弯半径全错 | 轴距是前后轴距离，轮距是左右轮距离 |
| 控制器用后轴，定位用前轴 | 有恒定横向偏移 | 全工程统一参考点 |
| 舵机中值不准 | 直行跑偏 | 给中值，调机械中值 |
| 舵机左右极限没限 | 烧舵机/顶死 | `pwm_min/pwm_max` 限死 |
| 转角符号反了 | 越修越偏 | 左转为正，检查舵机方向 |

## 2.7 自测

1. 轴距 0.25 m，前轮打 0.2 rad，转弯半径是多少？
2. 左转时，内轮转角比等效转角大还是小？
3. 为什么阿克曼车的内外轮不能用同一个转角？
4. 舵机中值 1500，k1=600，delta=0.2，PWM 是多少？
5. 控制器和定位的参考点不一致，会发生什么？

答案：

1. `0.25/tan(0.2) ≈ 1.23 m`。
2. 大。
3. 内侧轮走的圆半径小，转同样角度会侧滑。
4. `1500 + 600×0.2 = 1620 us`。
5. 车会有一个恒定的横向偏移，控制器以为在中心，其实一直偏一点。

全对，进入第 3 章。
