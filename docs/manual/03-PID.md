# 第 3 章 · PID：从原理到调参

> 学完这一章，你能回答：P、I、D 各管什么？为什么加了 I 会超调？为什么输出限幅后还会冲过头？串级 PID 为什么内环要快？

---

## 3.1 它是干什么的

PID 是**最常用的反馈控制器**。它看“目标”和“实际”差多少，算出一个输出，让实际值靠近目标。

智能车上到处是 PID：

- 舵机：目标转角 → 实际转角
- 电机：目标速度 → 实际速度
- 平衡车：目标角度 → 实际角度
- 云台：目标位置 → 实际位置

## 3.3 怎么用

最小示例：

```c
#include "sc/pid.h"

sc_pid_t pid;
sc_pid_init(&pid, 2.0f, 4.0f, 0.02f);   /* kp, ki, kd */
sc_pid_set_limits(&pid, -10.0f, 10.0f); /* 输出限幅 */

/* 每 10 ms 调用一次 */
float u = sc_pid_update(&pid, target, measured, 0.01f);
```

参数含义：

- `target`：目标值。
- `measured`：实际值。
- `dt`：这次和上次调用的时间间隔，单位秒。
- 返回值 `u`：控制量，比如 PWM、舵机角度。

**注意**：`ki`、`kd` 都按“秒”计，内部会乘 `dt`。换采样率不用改参数。

## 3.4 大白话原理

想象你开车要保持 60 km/h：

- **P（比例）**：现在 40，差 20，就多踩一点油门。差得越多，踩得越狠。
- **I（积分）**：一直差 5，说明油门踩得不够，慢慢再补一点。它看的是“累计差了多少”。
- **D（微分）**：速度正在快速上升，说明快到了，提前松一点油门，防止冲过头。

一句话：

```
P 看现在，I 看过去，D 看未来趋势
```

只有 P 会怎样？会稳定在一个“差一点”的速度（稳态误差）。
加 I 会怎样？能把误差磨到 0，但容易冲过头。
加 D 会怎样？能压住冲劲，但 D 太大会对噪声敏感，甚至振荡。

## 3.5 公式

连续形式：

```
u = Kp·e + Ki·∫e dt + Kd·de/dt
```

代码里的离散形式：

```
e = 目标 - 实际

P 项 = kp · e
I 项 = I 项 + ki · e · dt
D 项 = kd · (e - 上一次e) / dt

u = P + I + D
```

位置式和增量式的区别：

| | 位置式 | 增量式 |
|---|---|---|
| 输出 | 直接是控制量 | 是控制量的增量 |
| 适合 | 舵机、位置 | 电机、速度 |
| 积分 | 显式累加 | 隐含在输出里 |
| 设定值突变 | 微分会“踢”一下 | 输出不会跳变 |

代码切换：

```c
sc_pid_set_form(&pid, SC_PID_INCREMENTAL);
```

## 3.6 三个必须知道的改进

### 改进 1：抗积分饱和

问题：输出已经顶到最大值（比如 PWM 100%），但误差还在，积分继续累加。等误差反过来了，积分要很久才能退回来，于是大超调。

代码里的做法：输出饱和，且误差还在往同方向推，就撤销这次积分。

你会在实验里看到：`PI limit[0,1]` 和 `PI no limit` 的差别。

### 改进 2：积分分离

误差很大时先不用积分，靠 P 把系统拉回来；误差小了再启用积分。

```c
sc_pid_set_integral_separation(&pid, 0.5f);
```

适合启动、阶跃、大偏差。

### 改进 3：微分先行

设定值突然变化时，`de/dt` 是一个尖峰，输出会猛跳。

对“测量值”微分，而不是对“误差”微分：

```c
sc_pid_set_derivative_on_measurement(&pid, 1);
```

设定值变化时，测量值不会瞬间跳，所以没有冲击。

## 3.7 串级 PID

智能车常见结构：

```
外环：位置/角度 → 输出目标速度/角速度
内环：速度/角速度 → 输出 PWM
```

原则：

- 内环要比外环快 3~5 倍。
- 先调内环，再调外环。
- 外环输出要限幅。

例子：

```c
/* 外环：距离误差 → 目标速度 */
float v_target = sc_pid_update(&pos_pid, target_dist, dist, dt);

/* 内环：速度误差 → PWM */
float duty = sc_pid_update(&speed_pid, v_target, v_measured, dt);
```

## 3.9 常见错误

| 错误 | 现象 | 原因 | 怎么改 |
|---|---|---|---|
| 输出不限幅 | 一上电就冲 | 积分爆掉 | `sc_pid_set_limits` |
| I 太大 | 低频摆动、回中慢 | 积分饱和 | 加抗饱和/积分分离 |
| D 太大 | 高频抖动 | 放大噪声 | 加微分滤波、减小 D |
| 死区太大 | 稳态误差 | 小误差不动作 | 减小死区 |
| 换采样率后失稳 | 参数“变了” | ki/kd 按每拍算 | 本库按秒算，检查 dt |
| 位置式用在电机上 | 启动冲击 | 微分踢 | 改增量式或微分先行 |

## 3.10 自测

1. 只有 P，为什么会有稳态误差？
2. I 的作用是什么？代价是什么？
3. D 太大会发生什么？为什么？
4. 输出限幅后为什么还会超调？怎么解决？
5. 串级 PID 为什么先调内环？
6. 位置式和增量式分别适合什么？

答案：

1. 输出与误差成正比，要有输出就必须有误差。
2. 消除稳态误差；代价是超调、积分饱和。
3. 放大噪声、振荡；因为微分对变化率敏感。
4. 积分还在累加；加抗饱和/积分分离。
5. 内环不稳，外环怎么调都没用。
6. 位置式适合舵机/位置；增量式适合电机/速度。
