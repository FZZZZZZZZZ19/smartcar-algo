# 第 7 章 · 滤波与姿态解算

> 学完这一章，你能回答：传感器有噪声怎么办？卡尔曼和低通有什么区别？陀螺仪为什么会漂？互补滤波为什么能补？

---

## 7.1 它是干什么的

传感器读数都有噪声。滤波有两个目的：

1. **让信号平滑**，控制器不抖。
2. **融合多个传感器**，得到更可靠的估计。

姿态解算解决：车现在倾斜多少度？转弯角速度多少？

## 7.3 怎么用

### 一阶低通

```c
#include "sc/filter.h"
#include "sc/math_utils.h"

sc_lpf1_t lpf;
sc_lpf1_reset(&lpf, 0.0f);

/* 截止频率 30 Hz，周期 5 ms */
float alpha = sc_lpf_alpha_fc(30.0f, 0.005f);

float y = sc_lpf1_step(&lpf, raw, alpha);
```

### 中值滤波（去野值）

```c
sc_median_t med;
sc_median_init(&med, 3);
float y = sc_median_step(&med, raw);
```

### 二维卡尔曼（位置 + 速度）

```c
sc_kf2_t kf;
sc_kf2_init(&kf, 0.5f, 0.05f, 0.0f);  /* q, r, 初始位置 */

/* 每 5 ms */
sc_kf2_predict(&kf, 0.005f);
sc_kf2_update(&kf, measured_pos);

float pos = sc_kf2_pos(&kf);
float vel = sc_kf2_vel(&kf);
```

### 互补滤波（角度）

```c
sc_comp_t cf;
sc_comp_init(&cf, 0.0f, 0.98f);

/* gyro：陀螺角速度 rad/s；acc_angle：加速度计算的角度 */
float angle = sc_comp_update(&cf, gyro, acc_angle, 0.005f);
```

### Mahony（三轴姿态）

```c
sc_mahony_t m;
sc_mahony_init(&m, 0.5f, 0.05f);   /* kp, ki */

sc_mahony_update(&m, gx, gy, gz, ax, ay, az, 0.005f);

float roll, pitch, yaw;
sc_mahony_euler(&m, &roll, &pitch, &yaw);
```

### 陀螺零漂校准

```c
sc_gyro_cal_t cal;
sc_gyro_cal_init(&cal, 500);

while (!sc_gyro_cal_feed(&cal, gx, gy, gz, acc_norm, 1.0f)) {
    /* 车必须静止，持续采样 */
}

sc_gyro_cal_apply(&cal, &gx, &gy, &gz);
```

## 7.4 大白话原理

### 一阶低通

```
新输出 = α × 旧输出 + (1-α) × 新输入
```

α 越接近 1，越相信历史，越平滑，但**滞后越大**。

比喻：你听天气预报，不会因为今天突然热一天就改结论，而是慢慢调整。

**代价**：滤波太强，控制器拿到的信息就“过时”了，闭环会振荡。

### 中值滤波

取窗口里的中位数。个别野值（比如 1000 里突然出现一个 5000）会被直接忽略。

适合：ADC 偶发跳变、丢包。

### 卡尔曼

两句话：

1. **预测**：根据上一次的位置和速度，猜这一次在哪。
2. **更新**：拿测量值和预测值，按“谁更可信”加权。

`Q` 大 = 模型不可信，更信测量；`R` 大 = 测量噪声大，更信模型。

### 互补滤波

- 陀螺仪：短期准，长期漂。
- 加速度计：长期准，短期噪声大。

互补滤波就是“取长补短”：

```
角度 = α × (角度 + 陀螺×dt) + (1-α) × 加速度角度
```

α 接近 1，主要信陀螺；加速度计慢慢把漂移拉回来。

### Mahony

互补滤波只能处理一个轴。Mahony 用四元数同时处理三轴：

1. 用加速度计测到的重力方向，和陀螺积分出来的姿态比较。
2. 差多少，就修正多少陀螺。
3. 再积分四元数。

`kp` 管修正速度，`ki` 管消除零漂。

## 7.5 动手步骤

### 步骤 1：看滤波的滞后

写一个小程序：生成一个阶跃信号（0 到 1），分别用 α=0.5、0.9、0.99 滤波，打印每次输出。

```c
sc_lpf1_t f;
sc_lpf1_reset(&f, 0.0f);

for (int i = 0; i < 100; i++) {
    float x = (i >= 10) ? 1.0f : 0.0f;
    float y = sc_lpf1_step(&f, x, 0.9f);
    printf("%d %.4f\n", i, (double)y);
}
```

看达到 0.9 需要多少步。α 越大，越慢。

### 步骤 2：卡尔曼跟斜坡

```c
sc_kf2_t kf;
sc_kf2_init(&kf, 0.5f, 0.05f, 0.0f);

float t = 0.0f;
for (int i = 0; i < 500; i++) {
    t += 0.01f;
    sc_kf2_predict(&kf, 0.01f);
    sc_kf2_update(&kf, 2.0f * t);
}
printf("pos=%.3f vel=%.3f\n", (double)sc_kf2_pos(&kf),
       (double)sc_kf2_vel(&kf));
```

速度应该接近 2。改 `q` 和 `r`，看收敛快慢和噪声。

### 步骤 3：Mahony 静止测试

加速度计给 `(0,0,1)`，陀螺给 0，跑 2000 步，看 roll/pitch 是否接近 0。

再给陀螺一个 0.01 rad/s 的零漂，看 `ki` 能不能把姿态拉回来。

## 7.6 常见错误

| 错误 | 现象 | 怎么改 |
|---|---|---|
| 滤波太强 | 闭环振荡、响应慢 | 提高截止频率 |
| 滤波太弱 | 舵机抖 | 降低截止频率或加中值 |
| 中值窗口太大 | 输出台阶状 | 窗口 3~5 |
| 陀螺没校准 | 静止时角度一直漂 | 上电静止校准 |
| `ki` 太大 | 姿态缓慢摆动 | 减小 `ki` |
| 轴没对齐 | 俯仰和横滚混在一起 | 检查 IMU 安装方向 |
| 用错单位 | 角度差 57 倍 | 统一用弧度 |

## 7.7 自测

1. 一阶低通的 α 越大，输出更平滑还是更抖？滞后更大还是更小？
2. 中值滤波适合去掉什么噪声？
3. 卡尔曼的 `Q` 调大，更信模型还是更信测量？
4. 互补滤波为什么能同时利用陀螺和加速度计？
5. Mahony 的 `kp` 和 `ki` 分别管什么？
6. 陀螺零漂不校准，yaw 会怎样？

答案：

1. 更平滑；滞后更大。
2. 偶发脉冲/野值。
3. 更信测量（认为模型不准）。
4. 陀螺短期准、加速度计长期准，按频率互补。
5. `kp` 修正速度，`ki` 消除零漂。
6. 会随时间线性漂移。
