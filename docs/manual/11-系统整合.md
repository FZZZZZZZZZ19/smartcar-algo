## 9.1 一个完整的控制循环

```
┌─────────────────────────────────────────────────────────┐
│  1. 读传感器                                             │
│     摄像头/电磁 → e_y, e_psi, kappa                      │
│     编码器 → v                                           │
│     IMU → 姿态/角速度                                    │
└───────────────────────┬─────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│  2. 状态估计（可选）                                      │
│     滤波、卡尔曼、航迹推算                                │
└───────────────────────┬─────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│  3. 横向控制                                             │
│     e_y, e_psi, kappa → 路径跟踪 → delta                 │
└───────────────────────┬─────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│  4. 纵向控制                                             │
│     曲率 → 速度规划 → v_target → PID → duty              │
└───────────────────────┬─────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│  5. 执行器                                               │
│     delta → 舵机 PWM；duty → 电机 PWM                    │
└─────────────────────────────────────────────────────────┘
```

## 9.2 代码怎么接起来

下面是一个完整的 `control_task`，每 5 ms 调用一次：

```c
#include "sc/kinematics.h"
#include "sc/lqr.h"
#include "sc/motor.h"
#include "sc/pid.h"
#include "sc/servo.h"
#include "sc/speed_planner.h"

/* 这些是全局状态，实际项目里放在一个结构体里 */
static sc_ackermann_t   g_car;
static sc_lqr_track_t   g_lqr;
static sc_servo_t       g_servo;
static sc_motor_t       g_motor;
static sc_pid_t         g_speed_pid;
static sc_path_t        g_path;

static float g_s = 0.0f;      /* 当前路径位置 */
static float g_v_target = 0.0f;

void control_task(float dt) {
    /* ---------- 1. 读传感器 ---------- */
    float v = encoder_get_speed();          /* 你实现的 HAL */
    float e_y, e_psi;
    int idx;
    perception_get(&e_y, &e_psi, &idx);     /* 你实现的感知 */

    /* ---------- 2. 路径投影 ---------- */
    sc_path_project(&g_path, pose.x, pose.y, pose.theta,
                    idx, 40, &g_s, &e_y, &e_psi, &idx);

    float kappa = sc_path_curvature_at(&g_path, g_s, 0.25f);

    /* ---------- 3. 横向控制 ---------- */
    if (fabsf(v - g_lqr.v) > 0.4f) {
        sc_lqr_track_rebuild(&g_lqr, v);    /* 增益调度 */
    }
    float delta = sc_lqr_track_update(&g_lqr, e_y, e_psi, kappa);

    /* ---------- 4. 纵向控制 ---------- */
    g_v_target = speed_profile_at(g_s);     /* 你的速度剖面 */
    float duty = sc_pid_update(&g_speed_pid, g_v_target, v, dt);

    /* ---------- 5. 执行器 ---------- */
    float pwm = sc_servo_update(&g_servo, delta, dt);
    duty = sc_motor_update(&g_motor, duty, dt);

    servo_set_pwm(pwm);                     /* 你的 HAL */
    motor_set_duty(duty);                   /* 你的 HAL */
}
```

**关键点**：

- 感知只负责给 `e_y/e_psi`，不负责打角。
- 路径跟踪只负责 `delta`，不直接碰 PWM。
- 舵机和电机模型负责限幅、斜率、补偿。
- 每层只做一件事，出问题好定位。

## 9.3 任务怎么排

| 任务 | 周期 | 说明 |
|---|---|---|
| 电机 PWM | 10~20 kHz | 硬件定时器，不用 CPU |
| 编码器 | 1 ms | 读计数、算速度 |
| IMU | 2~5 ms | 读数据、姿态解算 |
| 控制 | 5~10 ms | 路径跟踪 + PID + 输出 |
| 电磁 ADC | 1~5 ms | DMA + 滤波 |
| 摄像头 | 20~50 ms | 采集、二值化、边线 |
| 调试输出 | 20~100 ms | 串口/无线 |

原则：

- 中断只做“读数据、置标志”，算法放主循环。
- 控制周期要稳定，用定时器触发，不要 `delay`。
- 慢任务（摄像头）不能阻塞快任务（控制）。

## 9.4 上电顺序

```
1. 关电机，舵机回中
2. 陀螺零漂校准（车必须静止）
3. 传感器自检
4. 等待发车信号
5. 使能电机
```

不要在陀螺没校准完就发车。

---

## 9.5 安全

| 保护 | 做法 |
|---|---|
| 输出限幅 | 舵机 PWM、电机占空比都限死 |
| 失控保护 | 摄像头超时 → 减速；IMU 超时 → 降级 |
| 看门狗 | 所有任务正常才喂狗 |
| 低压保护 | 电压低于阈值降速 |
| 急停 | 软件 + 硬件拨杆 |

## 9.6 移植到 MCU

### 第一步：写 HAL

算法层不直接碰寄存器，只调用这些函数：

```c
/* hal.h */
float encoder_get_speed(void);
void  servo_set_pwm(float pwm);
void  motor_set_duty(float duty);
void  imu_read(float *gx, float *gy, float *gz,
               float *ax, float *ay, float *az);
void  perception_get(float *e_y, float *e_psi, int *idx);
```

你只需要为每个主控实现这几个函数，算法层原样拷贝。

### 第二步：拷贝文件

```
include/sc/*.h
src/*.c
```

按需裁剪：电磁组不需要 `camera_line.c`，不用 LQR 可以不拷 `lqr.c`。

### 第三步：配置编译

- `-std=c11`
- 有 FPU 就用 `float`，不要用 `double`。
- `-ffunction-sections -fdata-sections` + `--gc-sections` 省 Flash。

### 第四步：台架测试

按顺序，每步通过再下一步：

1. 电机悬空：正转/反转、编码器符号、PWM 限幅。
2. 舵机：中值、左右极限、斜率、不顶死。
3. IMU：静止时角速度接近 0，倾角正确。
4. 摄像头/电感：能看到干净的二值图/归一化曲线。
5. 开环：固定 `delta`，车走预期方向；固定占空比，车走预期速度。

### 第五步：低速落地

1 m/s 直线 → 1 m/s 弯道 → 1.5 m/s → 2 m/s。
每圈记录：最大误差、是否出界、电池电压。

1. 读传感器 → 状态估计 → 横向控制 → 纵向控制 → 执行器。

4. 关电机、舵机回中、陀螺校准。
