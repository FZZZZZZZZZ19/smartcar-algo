# 第 8 章 · 速度规划与执行器

> 学完这一章，你能回答：弯道该跑多快？怎么保证进弯前刹得住？舵机 PWM 怎么标定？电机为什么有死区？

---

## 8.1 它是干什么的

路径跟踪决定“往哪打”，速度规划决定“跑多快”，执行器决定“指令能不能被执行”。

三件事：

1. **速度规划**：根据曲率、加减速能力，算出每个位置的目标速度。
2. **舵机**：把转角变成 PWM，带限幅和斜率限制。
3. **电机**：把控制量变成占空比，处理死区、掉压、斜率。

## 8.3 怎么用

### 曲率限速

```c
/* 曲率 0.5（半径 2 m），侧向加速度上限 4 m/s²，最高 5 m/s */
float v = sc_speed_limit_from_curvature(0.5f, 4.0f, 5.0f);
/* v = sqrt(4 / 0.5) = 2.83 m/s */
```

### 全局速度剖面

```c
/* kappa[] 是路径每点的曲率，ds 是点间距 */
float vprof[600];
sc_speed_profile_build(kappa, 600, 0.054f,
                       3.2f,   /* 最高速度 */
                       3.5f,   /* 侧向加速度上限 */
                       1.6f,   /* 加速度上限 */
                       2.2f,   /* 减速度上限 */
                       1,      /* 闭环 */
                       vprof,
                       4);     /* 迭代 4 次 */
```

### 梯形规划

```c
sc_trap_t trap;
sc_trap_plan(&trap, 10.0f, 0.0f, 0.0f, 2.0f, 1.0f, 1.0f);

float v = sc_trap_speed_at_distance(&trap, s, 0.0f, 0.0f, 1.0f, 1.0f);
```

### 舵机

```c
sc_servo_t servo;
sc_servo_init(&servo,
              1500.0f,  /* 中值 PWM */
              500.0f,   /* 每弧度 us */
              0.0f,     /* 二次项 */
              1000.0f,  /* 最小 */
              2000.0f,  /* 最大 */
              5.0f      /* 最大角速度 rad/s */
              );

float pwm = sc_servo_update(&servo, delta_cmd, dt);
```

### 电机

```c
sc_motor_t motor;
sc_motor_init(&motor,
              0.1f,    /* 死区占空比 */
              1.0f,    /* 最大占空比 */
              5.0f,    /* 每秒最多变化多少占空比 */
              8.0f     /* 标称电压 */
              );

sc_motor_set_battery(&motor, 7.2f);   /* 当前电压 */

float duty = sc_motor_update(&motor, cmd, dt);
```

## 8.4 大白话原理

### 曲率限速

过弯时，车需要的侧向加速度：

```
a = v² × 曲率
```

轮胎能提供的侧向加速度有限（`a_lat_max`）。所以：

```
v_max = sqrt(a_lat_max / 曲率)
```

弯越急，速度越低。直线曲率接近 0，取全局最高速度。

### 全局速度剖面

只知道每个点的限速还不够。直道末端速度很高，进弯前来不及刹车。

所以要扫三遍：

1. **曲率限速**：每个点先按弯道限速。
2. **反向扫描**：从后往前，保证每一点都能在到达下一点前刹到它的速度。
3. **正向扫描**：从前往后，保证加速能力够。

闭环路径首尾相连，要迭代几次让首尾约束收敛。

### 梯形规划

“加速 → 匀速 → 减速”三段。

```
加速距离 = (v_peak² - v0²) / (2·a_acc)
减速距离 = (v_peak² - v1²) / (2·a_dec)
```

如果两段加起来超过总距离，说明距离不够，要降低峰值速度。

### S 型规划

梯形规划的加速度是突变的，实车会冲击轮胎。S 型限制**加加速度（jerk）**：

```
加速度慢慢加上去，再慢慢减下来
```

代码是“在线版”：不需要预先知道距离，把速度平滑地推向目标。

### 舵机

```
PWM = 中值 + k1 × 角度 + k2 × 角度²
```

`k2` 补偿连杆非线性。`sc_servo_update` 还做了斜率限制，防止舵机被阶跃指令打坏。

### 电机死区

给小占空比，电机不转（静摩擦）。所以：

```
正向：duty = deadzone + cmd × (max_duty - deadzone)
反向：duty = -deadzone + cmd × (max_duty - deadzone)
```

掉压补偿：

```
duty = duty × 标称电压 / 当前电压
```

电压低了，多给一点占空比。

## 8.5 动手步骤

### 步骤 1：改侧向加速度

打开 `sim/sim_common.c`，找到：

```c
#define SIM_A_LAT 3.5f
```

改成 `2.0f`，`make sim`。记录：

- 圈速变慢多少？
- 最大横向误差变大还是变小？
- 速度曲线在弯道前是否提前下降？

### 步骤 2：改减速度

把 `SIM_A_DEC` 从 `2.2f` 改成 `1.0f`，再跑。观察速度剖面在弯前是否“刹不住”。

### 步骤 3：电机死区

写一个小程序：

```c
sc_motor_t m;
sc_motor_init(&m, 0.3f, 1.0f, 1000.0f, 8.0f);
sc_motor_reset(&m, 0.0f);

for (float cmd = 0.0f; cmd <= 1.0f; cmd += 0.1f) {
    printf("cmd=%.1f duty=%.3f\n", (double)cmd,
           (double)sc_motor_update(&m, cmd, 0.01f));
}
```

看 `cmd=0` 和 `cmd=0.1` 时输出是否已经跳过死区。

### 步骤 4：舵机斜率

把 `sc_servo_update` 的 `max_rate` 从 5 改成 1，给一个阶跃指令，看 PWM 要多久才到位。

## 8.6 常见错误

| 错误 | 现象 | 怎么改 |
|---|---|---|
| 只按曲率限速 | 进弯前刹不住 | 加反向扫描 |
| `a_lat` 估太大 | 弯道冲出 | 留 10~20% 余量 |
| 舵机不限幅 | 顶死、烧舵机 | `pwm_min/max` |
| 舵机不滤波 | 抖动 | 斜率限制/低通 |
| 电机死区不补偿 | 起步迟钝 | 死区补偿 |
| 掉压不补偿 | 电量低时变慢 | 电压补偿 |
| 输出变化太猛 | 打滑/冲击 | 斜率限制 |

## 8.7 自测

1. 曲率 1.0，`a_lat=4`，限速多少？
2. 为什么速度剖面要反向扫描？
3. 梯形规划距离不够时会怎样？
4. S 型规划比梯形多了什么限制？
5. 电机死区补偿解决什么问题？
6. 电池从 8.4 V 掉到 7.0 V，同样占空比，车会变快还是变慢？

答案：

1. `sqrt(4/1)=2 m/s`。
2. 保证进弯前能刹到弯道限速。
3. 峰值速度会被迫降低，甚至不可行。
4. 加加速度（jerk）限制。
5. 小占空比电机不转，起步迟钝。
6. 变慢；需要掉压补偿。
