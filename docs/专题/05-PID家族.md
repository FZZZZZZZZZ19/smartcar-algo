# 05 · PID 家族与高级控制

> 代码：`include/sc/pid.h`、`src/pid.c`、`include/sc/fuzzy_pid.h`、`src/fuzzy_pid.c`、`include/sc/adrc.h`、`src/adrc.c`
> 测试：`test_pid`

PID 是智能车电控里出现频率最高的算法：舵机打角、电机调速、平衡车直立、云台跟踪，到处都是它。但“会写 PID”和“会调 PID”是两回事。

这一章从离散形式讲到模糊 PID 和 ADRC，重点是**每个参数在做什么、什么时候会坏**。

---

## 1. 连续形式

```
u(t) = Kp e(t) + Ki ∫e dt + Kd de/dt
```

- `Kp`：误差越大，输出越大。决定响应速度。
- `Ki`：消除稳态误差。代价是超调、积分饱和。
- `Kd`：抑制变化，提供阻尼。代价是放大噪声。

代码里的 `ki`、`kd` 都按秒计：

```
u = kp*e + ki*∫e dt + kd*de/dt
```

所以换采样率不用改参数。这一点很重要：很多队伍的 PID 参数一换控制周期就失效，就是因为把 `ki`、`kd` 写成了“每拍”的量。

---

## 2. 位置式 vs 增量式

### 2.1 位置式

直接算输出：

```
e_k = setpoint - measured
integral += ki * e_k * dt
derivative = kd * (e_k - e_{k-1}) / dt
u = kp*e_k + integral + derivative
```

代码：

```c
sc_pid_t pid;
sc_pid_init(&pid, 2.0f, 4.0f, 0.02f);
sc_pid_set_limits(&pid, -10.0f, 10.0f);
float u = sc_pid_update(&pid, setpoint, measured, dt);
```

特点：

- 输出是绝对值，适合舵机、PWM。
- 有显式积分器，需要抗饱和。
- 设定值突变时微分项会“踢”一下。

### 2.2 增量式

算输出增量：

```
Δu = kp(e_k - e_{k-1}) + ki e_k dt + kd(e_k - 2e_{k-1} + e_{k-2})/dt
u_k = u_{k-1} + Δu
```

代码：

```c
sc_pid_set_form(&pid, SC_PID_INCREMENTAL);
```

特点：

- 输出自然累积，适合电机（尤其是带积分环节的执行器）。
- 没有显式积分器，抗饱和更简单。
- 设定值突变时输出不会跳变（因为只看误差变化）。
- 但如果执行器需要绝对位置，要额外维护 `u`。

**选哪个**：

- 舵机、位置伺服 → 位置式。
- 电机速度、电流 → 增量式。
- 平衡车直立环 → 位置式（角度是绝对量）。

### 2.3 第一次更新的坑

增量式第一次更新时，`e_{k-1}` 还没有值。如果初始化成 `e_k`，`Δu` 的 P 项就是 0，第一次没有输出。

代码里的处理：

```c
p->e1 = (p->form == SC_PID_INCREMENTAL) ? 0.0f : e;
```

位置式从当前误差开始，避免微分冲击；增量式从 0 开始，让第一次有正常的 P 响应。

## 3. 抗积分饱和

### 3.1 为什么会饱和

执行器有上限（PWM 最大 100%、舵机最多打 30°）。误差很大时，积分器持续累加，输出早就顶到上限了，但积分还在涨。等误差反向，积分要很久才能退回来，表现为**大超调、长时间不回中**。

### 3.2 三种常用方法

**方法一：积分限幅**

```
integral = clamp(integral, -I_max, I_max)
```

简单，但 `I_max` 不好定。

**方法二：条件积分（代码采用）**

输出已经饱和，且误差还在往同方向推，就撤销这次积分：

```c
if ((sat_hi && e > 0) || (sat_lo && e < 0)) {
    integ_new = p->integ;   // 不累加
}
```

好处：不需要额外参数，逻辑直观。

**方法三：反计算（back-calculation）**

```
u_sat = clamp(u)
integral += Kaw * (u_sat - u) * dt
```

用饱和误差反推积分。更平滑，但多一个 `Kaw` 参数。

### 3.3 积分分离

误差很大时先不用积分，靠 P 把系统拉回来；误差进入某个范围再启用积分：

```c
sc_pid_set_integral_separation(&pid, 0.5f);  // |e| > 0.5 时暂停积分
```

适合：启动、阶跃、大偏差场景。

## 4. 微分项的处理

### 4.1 微分冲击

设定值阶跃时，`de/dt` 是一个尖峰，输出会猛地一跳。

**微分先行**：对测量值微分，而不是对误差微分：

```
D = -kd * d(measured)/dt
```

```c
sc_pid_set_derivative_on_measurement(&pid, 1);
```

设定值变化时，测量值不会瞬间跳，所以没有冲击。

### 4.2 不完全微分

纯微分对噪声极其敏感。加一个一阶低通：

```
D_filt = α D_filt + (1-α) D_raw
```

```c
sc_pid_set_derivative_filter(&pid, 0.7f);
```

`α` 越小，滤波越强，滞后越大。通常 0.5~0.9。

### 4.3 死区

小误差时不动作，抑制舵机抖动：

```c
sc_pid_set_deadband(&pid, 0.01f);
```

死区别给太大，否则会引入稳态误差和极限环。

## 5. 串级 PID

智能车最常见的结构：

```
速度环：
    目标速度 → [PID] → PWM → 电机 → 编码器 → 实际速度
                                     ↑
                                  反馈

转向环：
    目标转角 → [PID] → 舵机 PWM → 前轮 → 摄像头/电磁 → 实际偏差
```

串级：

```
位置/角度外环 → 输出目标速度/角速度 → 速度/角速度内环
```

设计原则：

- **内环带宽 > 外环带宽 3~5 倍**。内环太快会放大噪声，太慢外环会振荡。
- 先调内环，再调外环。内环不稳，外环怎么调都没用。
- 外环输出要限幅，防止给内环一个不可能完成的目标。

### 5.1 速度环示例

```c
/* 外环：距离/位置 → 目标速度 */
float v_target = sc_pid_update(&pos_pid, target_distance, distance, dt);

/* 内环：速度 → PWM */
float duty = sc_pid_update(&speed_pid, v_target, v_measured, dt);
```

### 5.2 平衡车串级

```
直立环（角度 PD）→ 输出 PWM
速度环（编码器 PI）→ 输出角度补偿
转向环（陀螺仪 PD）→ 输出差速
```

三个环的输出相加，再限幅。直立环带宽最高，速度环最低。

## 6. 前馈

PID 是反馈，只有误差出现了才动作。前馈是“提前给”：

```
u = PID(e) + ff
```

```c
float u = sc_pid_update_ff(&pid, sp, meas, dt, ff);
```

典型前馈：

- 速度环：目标加速度 × 质量/增益。
- 转向：路径曲率对应的转角 `atan(L κ)`。
- 平衡车：重力补偿、摩擦补偿。

前馈能显著减小稳态误差和相位滞后，是“从能跑 to 跑得快”的关键。

## 7. 调参步骤

### 7.1 手动调参（推荐）

1. **只加 P**。从小到大，直到系统出现等幅振荡。记下此时的 `Ku` 和振荡周期 `Tu`。
2. **加 D**。先给 `Kd = 0.05~0.1 Ku Tu`，观察振荡是否被压住。
3. **加 I**。从很小的值开始，消除稳态误差。注意积分饱和。
4. **回头微调 P**。I 和 D 会影响最佳 P。

### 7.2 Ziegler-Nichols

| 控制器 | Kp | Ti | Td |
|---|---|---|---|
| P | 0.5 Ku | — | — |
| PI | 0.45 Ku | 0.83 Tu | — |
| PID | 0.6 Ku | 0.5 Tu | 0.125 Tu |

换算到本代码的单位：

```
ki = Kp / Ti
kd = Kp * Td
```

Z-N 给的是“激进”参数，实车通常要再保守 20~30%。

### 7.3 调参检查表

- 阶跃响应有没有超调？超调大 → 减小 P 或加 D。
- 有没有稳态误差？有 → 加 I。
- 有没有高频抖动？有 → 加微分滤波、减小 D、加死区。
- 大偏差时是否饱和？是 → 加积分分离/抗饱和。
- 换速度后是否还稳？否 → 增益调度或前馈。

## 8. 模糊 PID

### 8.1 思路

普通 PID 参数固定。模糊 PID 根据误差 `e` 和误差变化率 `ec` 实时调整 `Kp、Ki、Kd`：

```
Kp = Kp0 + ΔKp(e, ec)
Ki = Ki0 + ΔKi(e, ec)
Kd = Kd0 + ΔKd(e, ec)
```

### 8.2 模糊化

把 `e`、`ec` 归一化到 `[-3, 3]`，分成 7 个语言变量：

```
NB  NM  NS  ZO  PS  PM  PB
-3  -2  -1   0   1   2   3
```

三角形隶属度，中心在上述整数，半宽 1。

### 8.3 规则表

49 条规则，形式：

```
IF e is PB AND ec is ZO THEN ΔKp is ZO
```

代码里内置了经典的三张表（`RULE_KP`、`RULE_KI`、`RULE_KD`），规则索引 0~6 对应 NB~PB。

注意：经典 `Kd` 表在 `(ZO, ZO)` 处取 `NS`，所以零误差时 `ΔKd = -1`，不是 0。这是表本身的偏置，不是 bug。测试里专门验证了这一点。

### 8.4 解模糊

重心法：

```
ΔK = Σ(x * μ(x)) / Σ μ(x)
```

在 `[-3, 3]` 上离散求和。

### 8.5 使用

```c
sc_fuzzy_pid_t fp;
sc_fuzzy_pid_init(&fp, 2.0f, 3.0f, 0.02f, 1.0f, 5.0f);
sc_fuzzy_pid_set_scales(&fp, 0.6f, 1.0f, 0.01f);
sc_fuzzy_pid_set_limits(&fp, -10.0f, 10.0f);
float u = sc_fuzzy_pid_update(&fp, sp, meas, dt);
```

参数意义：

- `e_range`、`ec_range`：量程。`|e|` 超过量程会饱和到 ±3。
- `kp_scale` 等：模糊输出（-3~3）乘以缩放系数，得到实际参数修正量。

### 8.6 什么时候值得用

- 对象非线性强（舵机死区、轮胎侧偏）。
- 工况变化大（低速/高速、轻载/重载）。
- 你有时间调规则表和量化因子。

如果普通 PID 已经够用，模糊 PID 的收益不一定抵得上复杂度。

## 9. ADRC 自抗扰控制

### 9.1 三个部件

**TD（跟踪微分器）**：给设定值安排一个光滑的过渡过程，避免阶跃冲击。

```
v1(k+1) = v1 + h v2
v2(k+1) = v2 + h fhan(v1 - ref, v2, r, h)
```

**ESO（扩张状态观测器）**：用输出 `y` 和输入 `u` 估计状态 `z1、z2` 和“总扰动” `z3`。

```
e = z1 - y
z1 += h(z2 - β1 e)
z2 += h(z3 - β2 fal(e,0.5,h) + b0 u)
z3 += h(-β3 fal(e,0.25,h))
```

**NLSEF（非线性状态误差反馈）**：用 `fal` 函数做非线性组合，再用 `z3` 补偿扰动。

```
u0 = kp fal(e1,a1,δ) + kd fal(e2,a2,δ)
u = (u0 - z3) / b0
```

代码：`sc_adrc_update`。

### 9.2 整定

用带宽法：

```c
sc_adrc_set_bandwidth(&adrc, wc, wo, b0);
```

- `wc`：控制器带宽。`kp = wc²`，`kd = 2 wc`。
- `wo`：观测器带宽，通常 `3~5 wc`。`β1=3wo`，`β2=3wo²`，`β3=wo³`。
- `b0`：输入到输出的静态增益。估错了会影响扰动补偿。

**稳定性警告**：代码用的是显式欧拉离散。`wo * dt` 太大会发散。经验值：

```
wo * dt <= 0.15
```

`dt=5ms` 时 `wo <= 30`；`dt=10ms` 时 `wo <= 15`。开发时实测 `wo=30, dt=10ms` 会发散，`wo=8` 才正常。

### 9.3 适用场景

- 有较大未知扰动（摩擦、负载变化、风阻）。
- 模型不准，但又想要比 PID 更好的鲁棒性。
- 计算资源够（比 PID 多不少浮点运算）。

智能车上，ADRC 常用于电机速度环、平衡车直立环。

## 10. 排错表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 等幅振荡 | P 太大 / D 太小 / 相位滞后 | 减小 P，加 D，检查滤波 |
| 低频摆动 | I 太大 / 积分饱和 | 减小 I，加抗饱和 |
| 高频抖动 | D 太大 / 噪声 | 加微分滤波，减小 D |
| 稳态误差 | I 太小 / 死区太大 | 加 I，减小死区 |
| 启动超调 | 积分累积 | 积分分离、设定值斜坡 |
| 反向时迟钝 | 死区/摩擦 | 死区补偿、前馈 |
| 换速度后失稳 | 增益未调度 | 速度相关增益或前馈 |
