# 04 · 滤波与姿态解算

> 代码：`include/sc/filter.h`、`src/filter.c`、`include/sc/attitude.h`、`src/attitude.c`
> 测试：`test_filter`、`test_attitude`

传感器都有噪声。滤波不是为了“让曲线好看”，而是为了让控制器拿到**相位滞后可控、噪声足够小**的信号。这一章从最简单的低通讲到 Mahony 姿态解算。

---

## 1. 一阶低通

### 1.1 公式

```
y_k = α y_{k-1} + (1-α) x_k
```

`α` 越接近 1，越相信历史，输出越平滑，但滞后越大。

由时间常数 `τ` 或截止频率 `fc` 换算：

```
α = τ / (τ + dt)
α = exp(-2π fc dt)
```

代码：

```c
sc_lpf1_t lpf;
sc_lpf1_reset(&lpf, 0.0f);
float alpha = sc_lpf_alpha_tau(0.02f, 0.005f);  // τ=20ms, dt=5ms
float y = sc_lpf1_step(&lpf, x, alpha);
```

### 1.2 选参数

- 速度环：`fc` 20~50 Hz。
- 舵机角度：`fc` 10~20 Hz。
- 电感：`fc` 50~100 Hz。

经验：**滤波截止频率至少比控制环带宽高 3~5 倍**，否则相位滞后会吃掉相位裕度，闭环振荡。

### 1.3 相位滞后

一阶低通在频率 `f` 处的相位滞后：

```
φ = -atan(2π f τ)
```

如果你的控制周期是 5 ms，滤波器时间常数 20 ms，那么在 10 Hz 处的滞后约 51°。这不是小数目。

## 2. 滑动平均与中值

### 2.1 滑动平均

```
y_k = (x_k + x_{k-1} + ... + x_{k-N+1}) / N
```

噪声标准差降为 `σ/√N`，但引入 `(N-1)/2` 个采样的滞后。

适合：ADC 采样、速度反馈。

### 2.2 中值

取窗口内中位数。对**脉冲噪声**（偶发跳变、丢包）特别有效，而且不会像平均那样被极端值拖偏。

```c
sc_median_t med;
sc_median_init(&med, 3);
float y = sc_median_step(&med, x);
```

实战组合：`中值(3) → 低通`，先去掉野值，再平滑。

## 3. 限幅、斜率限制、死区

这三个不是“滤波”，但经常一起用：

| 工具 | 作用 | 函数 |
|---|---|---|
| 限幅 | 防止异常值进入控制器 | `sc_clampf` |
| 斜率限制 | 限制舵机/电机变化率 | `sc_slew_limit` |
| 死区 | 小误差不动作，抑制抖动 | `sc_deadband` |

舵机特别需要斜率限制。一个阶跃指令可能让舵机瞬间打到极限，电流冲击大、机械磨损快。代码里 `sc_servo_update` 内置了。

## 4. 卡尔曼滤波

### 4.1 一维卡尔曼

模型：

```
x_{k+1} = x_k + w,     w ~ N(0, Q)
z_k     = x_k + v,     v ~ N(0, R)
```

预测：

```
p = p + Q
```

更新：

```
K = p / (p + R)
x = x + K (z - x)
p = (1 - K) p
```

代码：`sc_kf1_step`。

`Q` 大表示“模型不可信，更相信测量”；`R` 大表示“测量噪声大，更相信模型”。

一维卡尔曼适合：静止零漂、温度、单传感器测距。

### 4.2 位置 + 速度卡尔曼

状态 `[位置, 速度]`，匀速模型：

```
F = [1 dt; 0 1]
```

过程噪声用“白噪声加速度”模型：

```
Q = q * [dt^4/4  dt^3/2]
        [dt^3/2  dt^2  ]
```

代码：`sc_kf2_predict` / `sc_kf2_update`。

用途：编码器测速 + 位置融合；视觉位置 + 速度估计。

调参直觉：

- `q` 大：认为车可能突然加速，滤波器反应快，但噪声大。
- `r` 大：认为测量不准，输出平滑但滞后。

### 4.3 卡尔曼不是万能的

- 模型错了（比如实际是匀加速，你假设匀速），滤波会滞后。
- `Q`、`R` 不是常数时（噪声随速度变化），需要自适应。
- 计算量比低通大，但在 MCU 上做 2 状态卡尔曼完全没问题。

## 5. 互补滤波

陀螺仪短期准、长期漂；加速度计长期准、短期噪声大。互补滤波把两者按频率分开：

```
angle = α (angle + gyro * dt) + (1 - α) acc_angle
```

代码：

```c
sc_comp_t cf;
sc_comp_init(&cf, 0.0f, 0.98f);
float angle = sc_comp_update(&cf, gyro_rate, acc_angle, dt);
```

`α = 0.98` 对应时间常数约 `α/(1-α) * dt = 49 * dt`。`dt=5ms` 时约 0.25 s。

这是最简单、最常用的姿态融合。缺点是：加速度计在车加速/刹车时会测到惯性力，角度会瞬间错；需要根据加速度模长做可信度判断。

## 6. Mahony 四元数姿态解算

互补滤波只能处理一个轴。要同时得到 roll/pitch/yaw，用四元数。

### 6.1 四元数

```
q = [w, x, y, z]，单位四元数
```

旋转矩阵：

```
R = [1-2(y²+z²)   2(xy-wz)     2(xz+wy) ]
    [2(xy+wz)     1-2(x²+z²)   2(yz-wx) ]
    [2(xz-wy)     2(yz+wx)     1-2(x²+y²)]
```

欧拉角：

```
roll  = atan2(2(wx+yz), 1-2(x²+y²))
pitch = asin(2(wy-zx))
yaw   = atan2(2(wz+xy), 1-2(y²+z²))
```

代码：`sc_quat_to_euler`、`sc_quat_to_rot`。

### 6.2 Mahony 算法

核心思想：用加速度计测到的重力方向，去修正陀螺积分出来的姿态。

1. 归一化加速度 `a`。
2. 用当前四元数估计重力方向 `v`：

```
vx = 2(q1 q3 - q0 q2)
vy = 2(q0 q1 + q2 q3)
vz = q0² - q1² - q2² + q3²
```

3. 误差 = `a × v`：

```
ex = ay vz - az vy
ey = az vx - ax vz
ez = ax vy - ay vx
```

4. PI 修正陀螺：

```
gx += kp ex + ki ∫ex dt
...
```

5. 四元数积分：

```
q0 += 0.5(-q1 gx - q2 gy - q3 gz) dt
q1 += 0.5( q0 gx + q2 gz - q3 gy) dt
q2 += 0.5( q0 gy - q1 gz + q3 gx) dt
q3 += 0.5( q0 gz + q1 gy - q2 gx) dt
```

6. 归一化。

代码：

```c
sc_mahony_t m;
sc_mahony_init(&m, 0.5f, 0.05f);   // kp, ki
sc_mahony_update(&m, gx, gy, gz, ax, ay, az, dt);

float roll, pitch, yaw;
sc_mahony_euler(&m, &roll, &pitch, &yaw);
```

### 6.3 参数

- `kp`：姿态误差修正速度。0.1~1.0。太大对振动敏感，太小收敛慢。
- `ki`：消除陀螺零漂。0.001~0.05。太大可能振荡。

如果车静止时 yaw 一直缓慢漂，说明 `ki` 不够或者陀螺零漂没校准。

### 6.4 万向节锁

欧拉角在 pitch = ±90° 时奇异。智能车一般不会到 90°，但做翻滚/越野时要注意。四元数本身没有这个问题，只是转欧拉角时会出现。

## 7. 陀螺零漂校准

上电后车必须静止，采集 N 个样本求平均作为零漂：

```c
sc_gyro_cal_t cal;
sc_gyro_cal_init(&cal, 500);

while (!done) {
    done = sc_gyro_cal_feed(&cal, gx, gy, gz, acc_norm, 1.0f);
}
sc_gyro_cal_apply(&cal, &gx, &gy, &gz);
```

代码里有一个保护：加速度模长偏离 1g 超过 35% 时，认为车在动，重新计数。防止上电时有人碰车导致校准错误。

零漂会随温度变化。比赛前热身几分钟，让传感器温度稳定后再校准。

| 场景 | 传感器 | 方法 |

| 速度估计 | 编码器 | 低通 + 卡尔曼 |

## 9. 常见坑

1. **轴没对齐**：IMU 的 x 轴和车头方向不一致。装车前画好坐标系，代码里做轴交换。
2. **振动**：电机振动会让加速度计噪声爆炸。加海绵减震，或在 Mahony 里降低 `kp`。
3. **加速度计受惯性力**：车加速时 `ax` 不为 0，倾角会错。用加速度模长判断可信度。
4. **陀螺量程**：选 ±500°/s 还是 ±2000°/s？量程小分辨率高，但撞车可能饱和。
5. **采样率**：Mahony 需要稳定、较高的采样率（≥200 Hz）。用定时器中断，不要在 main 循环里跑。
6. **浮点**：MCU 没有 FPU 时，四元数运算较慢。可以用定点数或降低更新率。
